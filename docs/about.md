# 关于

这里是 lumikok 的个人知识库，用来沉淀技术笔记、记录学习过程，并整理算法练习。

站点使用 VitePress 与 `@sugarat/theme` 构建。内容按用途分为四部分：长期维护的[知识库](/contents/notes/)、按日期归档的[学习日志](/contents/journal/)、[随笔](/contents/essays/)和[题解](/contents/problems/)。

源代码与更新记录可以在 [GitHub](https://github.com/lumikok) 查看。
