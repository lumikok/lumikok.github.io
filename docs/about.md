# 关于我

你好，我是 **lumikok**，一名计算机专业学生。

我正在学习数据结构与算法、Web 后端和 AI 相关技术，也在尝试把学到的东西用于真实的小项目。相比单纯收集知识，我更希望通过练习、项目和复盘，逐渐建立能够独立分析和解决问题的能力。

## 我目前在做什么

- 通过 [FastAPI 记账本](/contents/projects/learning/tally-book)完成了一次后端、数据库与前后端联调实践。
- 持续维护[个人知识库](/contents/notes/)，整理真正理解并愿意长期保留的内容。
- 借助 AI 探索个人产品与学习工具，例如[拾光 LearnTrace](/contents/projects/personal/learntrace)。
- 继续巩固数据结构、算法和计算机基础。

## 这个网站

这个网站是我的公开学习档案，也是经过筛选后的个人知识空间：

- [文章](/contents/essays/)用于完整表达阅读、思考、经验与复盘；
- [知识库](/contents/notes/)用于长期维护可查询的主题笔记；
- [项目](/contents/projects/)记录个人产品、学习项目与技术探索；
- [足迹](/contents/journey/)记录重要的开始、完成和方向变化。

网站基于 VitePress 和 `@sugarat/theme` 模板持续改造。

更多代码和公开记录可以在 [GitHub](https://github.com/lumikok) 查看。
