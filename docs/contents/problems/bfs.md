# 广度优先搜索

层序最短距离、入队前标记与多源初始化的共用机制见[广度优先搜索](../notes/algorithms/searching/07_BFS.md)。本页保留题目特有的状态、转移和边界。

## P1443：马的遍历

[题目](https://www.luogu.com.cn/problem/P1443)：在 `n×m` 棋盘上，从给定位置出发，求马到每个位置的最少步数，不可达位置输出 `-1`。

每个格子是一个状态，一次马步是一次等代价转移。沿用单源 BFS，只需将后继改为八个方向，排除棋盘外坐标：

```cpp
// 保留自原笔记的方向数组；dx[k] 与 dy[k] 必须成对使用。
const int dx[] = {1, 1, -1, -1, 2, 2, -2, -2};
const int dy[] = {2, -2, 2, -2, 1, -1, 1, -1};
```

距离先全部设为 `-1`，起点设为 `0` 并入队。每个新格子的距离等于前驱距离加一。本题要输出整个距离矩阵，不能在找到某一个目标后提前停止；棋盘较小时可能有格子不可达，不应将它们改成 `0`。每格至多入队一次，检查八个方向，时间与空间均为 O(nm)。

## P1332：多个感染源同时扩散

[题目](https://www.luogu.com.cn/problem/P1332)：感染源每小时向上下左右扩散一格，查询给定位置最早何时感染。没有障碍，各源同时开始。

将所有不同感染源设为零距离并入队，只做一次 BFS。查询答案是到最近源点的距离，不是到第一个输入源点的距离；源点本身的答案为 `0`。实现见[多源 BFS](../notes/algorithms/searching/07_BFS.md#多源-bfs-把所有起点放在第零层)。

一个用于检查源点竞争的例子：`5×4` 网格，源点为 `(1,1)`、`(5,4)`，依次查询 `(3,3)`、`(5,3)`、`(2,4)`，应得到 `3、1、3`。其中 `(5,3)` 距离后输入的源点仅一步，能检出只从第一个源点传播的问题。此题没有障碍，结果也可用到各源曼哈顿距离的最小值交叉检查；有障碍时不能直接使用这个公式。

训练文件 `01_date/2026-10/P1332.cpp` 保存查询后按输入顺序输出。含读入和查询，时间为 O(nm+a+b)，空间为 O(nm+b)，其中 `a` 为源点数，`b` 为查询数。逐个源点重复 BFS 再取最小值会重复扫描网格，多源初始化避免了这一开销。

## CF520B：整数状态与搜索上界

[Two Buttons](https://codeforces.com/problemset/problem/520/B)：从正整数 `n` 出发，每次可以乘二或减一，过程中必须保持正数，求变为 `m` 的最少操作数。原题 `1<=n,m<=10000`。

### 状态与有限搜索范围

当前数值 `x` 就是状态，后继为 `2*x`、`x-1`，每次操作代价都是一步，因此可以 BFS。题目允许任意大的正整数，但程序不能为无限状态分配数组；必须先证明保留多大范围足够。

当 `x>=m` 时，直接递减 `x-m` 次最优。递减一次只能减少一；若中途翻倍，数值反而增加，之后还要用更多次递减消除增量，所以不可能比直接递减更短。特别地，`n>m` 可直接输出 `n-m`。

当 `n<m` 时，可选一条最优路线，使其每次在 `x<m` 时才翻倍、首次到达或越过 `m` 后只递减。因为 `x<m`，翻倍后 `2*x<2*m`，所以这条路线不需要到达 `2*m` 及以上。由此，保留闭区间 `[1,2*m]` 是安全的；使用统一写法 `L=2*max(n,m)` 也足够，但不是最紧上界。

不能只保留 `[1,m]`：例如 `n=4,m=5` 时，路线 `4→3→6→5` 需要越过目标。若上界只取 `5`，由于生成奇数 `5` 的前驱只能是 `6`，搜索反而会把目标判为不可达。

### 从范围到数组长度

先确定范围，再对应存储，而不是只修改某个比较符号：

1. 合法搜索状态为 `1<=next<=L`。
2. 使用数值作下标，就需要能访问 `dist[L]`，因此分配 `L+1` 个元素；零号位置不用。
3. 检查范围必须在 `dist[next]` 访问之前，避免非法下标先被求值。
4. 入队前写距离，避免翻倍和递减形成的环导致重复扩展。

下面整理自训练文件 `01_date/2026-10/CF520B.cpp`：保留正向 BFS 与 `2*max(n,m)` 上界，将距离数组 `a` 更名为 `dist`，合并两个后继的重复处理，提取为函数并补充步骤注释。上面的界限推导用于补全实现依据。

```cpp
#include <algorithm>
#include <queue>
#include <vector>
using namespace std;

// 前提：1 <= n,m <= 10000，保留原题数值范围。
int minButtonPresses(int n, int m) {
    if (n >= m) return n - m;  // 1. 无需翻倍即可取得最优解。

    int limit = 2 * max(n, m);
    vector<int> dist(limit + 1, -1);  // 2. 闭区间右端点也要有存储位置。
    queue<int> q;
    dist[n] = 0;
    q.push(n);

    while (!q.empty()) {
        int x = q.front();
        q.pop();
        if (x == m) return dist[x];

        // 3. 隐式生成两条边，不必预先建图。
        for (int next : {x * 2, x - 1}) {
            if (next < 1 || next > limit) continue;
            if (dist[next] != -1) continue;
            dist[next] = dist[x] + 1;  // 4. 入队前标记并确定最短距离。
            q.push(next);
        }
    }
    return -1;  // 对原题合法输入不会发生。
}
```

每个状态至多入队一次、生成两个后继，BFS 分支时间和空间均为 O(L)。按原题范围，`L<=20000`、候选 `2*x<=40000`，`int` 足够；若扩大输入范围，还必须检查计算后继与上界时是否溢出，不能以“检查后继合法”替代溢出防护。
