# 题解模板

沿用“来源—核心思路—关键代码—注意点”的简洁结构，按题目需要补充推导和复杂度。下面的占位说明用于写作时替换，不要求每题都保留全部栏目。

## 题号与题名

- **来源**：填写原题链接，简述目标和影响解法的关键约束。
- **核心思路**：说明状态或维护对象、关键转移，以及方案为什么正确。
- **关键代码**：保留足以理解算法的完整函数或必要入口；标清来自原源码、经整理的实现或补充示例，避免堆放无关模板。
- **注意点**：留下有价值的真实错误、易混边界或代表例子；能力评价和待办留在学习记录中。
- **复杂度**：定义变量含义，说明时间与额外空间，递归实现计入调用栈。
