# 项目

这里区分个人产品、学习项目和教程复现，不用仓库数量代替实际能力。算法练习、早期笔记和实习记录属于[成长足迹](/contents/journey/)，不作为项目展示。

## 拾光 LearnTrace

**类型：个人产品 · Vibe Coding**  
**时间：2026.09—至今**  
**状态：持续迭代**

拾光是一个单用户、本地运行的学习记录应用，支持学习记录、条件搜索、日历热力图、每周回顾、成长节点以及本地备份与恢复。当前已经完成 Windows 桌面打包和跨电脑运行验收。

这是一个由我提出需求、决定产品取舍并负责反馈与验收，代码主要由 AI 完成的个人产品。它能够说明我在发现个人问题、描述需求、迭代产品和验证结果方面的实践，但不把 AI 生成的实现包装成独立手写开发能力。

- [GitHub 仓库](https://github.com/lumikok/LearnTrace)
- [v0.4.0 Release](https://github.com/lumikok/LearnTrace/releases/tag/v0.4.0)

## FastAPI 记账本

**类型：学习项目**  
**时间：2026.06—至今**  
**状态：持续学习与完善**

这是一个用于学习和检验 FastAPI 与基础前端知识的记账本项目。当前实现了开销增删改查、分类筛选、分页、支出统计图表、响应式页面以及 FastAPI 单端口访问。

项目的重点不是产品创新，而是把路由、数据模型、数据库、异常处理、原生前端、接口调用和图表展示连接成一条完整链路。

- [GitHub 仓库](https://github.com/lumikok/tally-book-lp)
