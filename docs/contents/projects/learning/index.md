# 学习项目

这里收录学习过程中承担不同作用的项目：C 语言通讯录用于基础知识综合练习，AI 智能伴侣用于教程复现与应用流程入门，FastAPI 记账本用于连接后端、数据库和前端，Todo API 用于在新业务中迁移已有知识并练习工程方法。

各项目详情记录项目作用、具体学习内容与实际实现；教程复现和 AI 辅助情况也分别注明。围绕概念开展的小规模对照实验另见[学习实验](/contents/projects/labs/)。

<!-- AUTO-CONTENT:CATEGORY:START -->
- [Todo API](/contents/projects/learning/todo-app) — 迁移记账本中的前后端知识，练习接口测试、需求变化与模块拆分。
- [FastAPI 记账本](/contents/projects/learning/tally-book) — 作为 FastAPI 与基础前端的学习载体，连接接口、数据库、页面和统计图表。
- [AI 智能伴侣复现](/contents/projects/learning/ai-partner-repro) — 通过教程复现认识大模型对话应用，练习 Streamlit、流式调用与会话持久化。
- [C 语言通讯录](/contents/projects/learning/mini-address-book) — 用通讯录业务综合练习 C 语言的结构体、动态内存、文件保存与输入处理。
