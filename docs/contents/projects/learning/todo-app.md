# Todo API

这是在 2026 年 10 月实际开展并完成的个人学习项目，用任务管理业务练习 Python、FastAPI、数据库和原生前端。

## 项目作用

Todo API 承担从记账本项目到后续 Agent 工程实践之间的迁移与工程桥接：换成任务管理业务，重新应用请求校验、数据库操作和页面交互，并通过需求变化、隔离测试与模块拆分练习工程方法。

## 已实现功能

- 创建任务，按计划日期查询，并按优先级与创建时间排序；
- PATCH 部分更新，区分省略字段与显式清空；
- 完成任务时记录首次完成时间，区分正常与逾期完成；
- 删除任务，并处理不存在或重复操作；
- 原生页面支持创建、查询、统一弹窗编辑和删除，完成操作通过接口文档调用。

## 学习内容

### 复习与迁移

- Python 的类型提示、日期时间、异常、排序与模块导入；
- FastAPI 的请求与响应模型、路径与查询参数、状态码、依赖注入和数据库 CRUD；
- 原生前端的表单、DOM、事件、`fetch` 与异步请求，连接页面操作与后端数据。

### 新增与深化

- 用 `Literal` 限定状态，使用 `UUID` 生成和校验任务标识；
- PATCH 区分省略与 `null`，先校验候选值再修改数据，维护任务状态与首次完成时间；
- 使用 SQLModel、aiosqlite 与异步会话，处理事务提交、应用生命周期与资源清理；
- 用 pytest、临时数据库和 AsyncClient 进行隔离接口测试，检查失败后的数据以及依赖覆盖和恢复；
- 分离 HTTP 模型、数据库表、路由和依赖，追踪一次需求变化对前后端与测试的影响；
- 区分写入失败与写入成功后的刷新失败，保留失败输入；备份后为旧表添加字段，理解自动建表与已有表结构更新的区别。

## 开发方式与范围

这是个人实践，学习与开发中使用 AI 讲解、提示和代码审查。我实现查询、创建和删除等交互；统一编辑弹窗与保存期间的交互封锁使用 AI 辅助实现，并参与需求确认、代码阅读与结果检查。
