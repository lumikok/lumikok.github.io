# AI 智能伴侣复现

这是跟随公开教程完成的 Streamlit AI 智能伴侣复现项目。在原有思路上调整了部分代码、交互和页面布局，并整理了单独的学习笔记。

## 主要功能

- 自定义伴侣昵称和人物设定；
- 调用 OpenAI 兼容接口进行流式对话；
- 新建、加载和删除历史会话；
- 使用本地 JSON 文件保存聊天记录；
- 使用 Streamlit 构建控制面板和聊天界面。

通过这次复现，我第一次完整接触了 Streamlit 状态管理、大模型流式调用、System Prompt 和本地会话持久化。
