# C 语言通讯录

这是学习 C 语言期间完成的简易通讯录，也是我较早保留下来的完整练习项目。仓库记录了两个版本的实现过程。

## 主要功能

- 添加联系人；
- 删除联系人；
- 查找联系人；
- 显示全部联系人信息。

项目练习了结构体、文件操作、动态内存、字符串处理、命令行交互以及输入检查等基础内容。
