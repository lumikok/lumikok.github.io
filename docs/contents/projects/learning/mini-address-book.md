# C 语言通讯录

这是学习 C 语言期间完成的简易通讯录，也是我较早保留下来的完整练习项目。仓库记录了两个版本的实现过程。

## 项目作用

用通讯录业务把 C 语言中的数据组织、内存管理、文件操作和命令行交互串起来，从单个语法练习过渡到一个可反复使用和修改的小程序。

## 学习内容

- 用结构体组织联系人信息，并实现添加、删除、查找与显示；
- 使用动态内存保存联系人数据，练习字符串处理；
- 使用文件保存和读取联系人信息；
- 处理命令行菜单与用户输入，加入必要的输入检查，并保留版本迭代过程。

## 主要功能

- 添加联系人；
- 删除联系人；
- 查找联系人；
- 显示全部联系人信息。
