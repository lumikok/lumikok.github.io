# 依赖注入

## 什么是依赖注入

相当于，把你需要的工具或者数据写成函数，然后用 `Depends(函数名) ` 作为参数，让 FastAPI 自动调用函数，并将结果传入。

**本质**：接口不自己去拿“工具”，而是伸手去要，FastAPI 给你递过来。

比如鉴权逻辑：

```python
from typing import Annotated
from fastapi import Header,Depends,HTTPException,FastAPI

@app.get("/expense")
def list_expenses(token: Annotated[str,Header(...)]):
	if(token != "secret"):
		raise HTTPException(401)
	return token
```

这段代码用于检查用户是否传入了符合条件的 `token` ，当许多接口都要有这段鉴权的话，当逻辑 `secret` 修改时，会牵一发而动全身。

此时，就体现了依赖注入的作用，可改写为依赖注入：

```python
from typing import Annotated

from fastapi import Header,Depends,HTTPException,FastAPI

def verify_token(token: Annotated[str,Header(...)]):
	if token != "secret":
		raise HTTPException(401)
	return token

@app.get("/expenses")
def list_expenses(token: Annotated[str,Depends(verify_token)]):
	return ...
```

 `Depends(verify_token)` 的作用：FastAPI 看到 `Depends`，会在执行你的接口前，先去调用 `verify_token` ，把它的返回值塞给 `token` 参数。

## 为什么需要依赖注入

由上述例子可知，依赖注入能够解决代码逻辑重复使用导致的冗余问题，本质为了**复用**。

## 补充

依赖可**嵌套**：

```python
def get_db(): ...
def get_user(db = Depends(get_db)): ...   # get_user 依赖 get_db
def get_items(user = Depends(get_user)): ...  # get_items 依赖 get_user
```

FastAPI 会按顺序：get_db → get_user → get_items。**像洋葱一层层剥**。
