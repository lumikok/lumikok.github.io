# 错误处理

## `HTTPException`

可以使用 `HTTPException` 返回 HTTP 错误响应：

```python
from fastapi import HTTPException

...
raise HTTPException(status_code=404, detail="具体错误信息")
...
```

这样，客户端将会接收到 HTTP 状态码以及具体的错误信息（JSON 格式）：

```json
{
	"detail": "具体错误信息"
}
```

**补充**：`detail` 参数可以传递任何能转换成 `JSON` 的值（自动转换）。

## 自定义响应头

**补响应头**：

为错误响应添加自定义响应头，本质上就是服务器额外附加给客户端的一些“元信息”。

它通常**不是给用户直接看的**，而是给浏览器、APP、其他服务器或客户端程序使用，用来传递认证方式、限流信息、请求追踪 ID、API 版本、缓存策略等控制信息。

**方式**：多写一个参数 `headers`。

```python
raise HTTPException(
    status_code=404,
    detail="Item not found",
    headers={
        "X-Error":"There goes my error"
    }
)
```

**注意**：`X-Error` 只是演示而已，不要用无意义的响应头。

## 覆盖默认异常处理器

**作用**：

- 修改 FastAPI 默认的异常响应格式。
- 实现全局统一的错误返回。
- 可以记录日志、增加调试信息或适配企业接口规范。

**适用场景**：

- 企业项目统一响应格式。
- 自定义错误页面或 JSON 返回。
- 全局异常捕获。

**示例**：

```python
from fastapi import FastAPI
from fastapi.responses import JSONResponse
from fastapi.exceptions import RequestValidationError

app = FastAPI()

@app.exception_handler(RequestValidationError)
async def validation_exception_handler(request, exc):
    return JSONResponse(
        status_code=400,
        content={
            "code": 400,
            "message": "参数错误"
        }
    )
```

覆盖了 `RequestValidationError `。

## 自定义异常处理器

**解决的问题**：避免错误处理逻辑更改，导致多处 `raise` 需要修改造成的麻烦。

**示例**：

**第 1 步：定义一个自定义异常类**

```python
# ===== 自定义异常 =====
# 继承 Exception 表示这是个异常；FastAPI 能识别并处理它
class ExpenseNotFound(Exception):
    """当查不到某笔开销时抛出"""
    def __init__(self, expense_id: int):
        self.expense_id = expense_id
```

**第 2 步：注册一个全局处理器**，告诉 FastAPI "遇到这个异常该怎么响应"

```python
# ===== 注册异常处理器 =====
# @app.exception_handler 告诉 FastAPI：遇到 ExpenseNotFound 异常时，用这个函数处理
@app.exception_handler(ExpenseNotFound)
async def expense_not_found_handler(request, exc: ExpenseNotFound):
    """把 ExpenseNotFound 异常统一转成 404 响应"""
    return JSONResponse(
        status_code=404,
        content={"detail": f"未找到 id={exc.expense_id} 的开销记录"},
    )
```

**第 3 步：顶部 import 加 `JSONResponse` **

```python
from fastapi.responses import JSONResponse # ← 新增
```

 **4 步：把接口里的 `raise HTTPException` 换成自定义异常**
 
```python
raise ExpenseNotFound(expense_id) # ← 改成自定义异常
```

这样，如果有变化，只需要更改全局处理器即可。
