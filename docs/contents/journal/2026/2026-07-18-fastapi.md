# 路径操作配置

主要涉及路径操作装饰器的配置参数

**摘要和描述**：

1. `summary=...`：api 的标题；
2. `description=...`：对 api 的具体描述；

**标签**：

1. `tag=["str"]`：str 组成的 list，一般只有一个 str，api 的标签；
2. `class Tags(Enum)`：标签较多时可用；

**响应描述**：

`response_description=...`：定义响应的描述说明；

**注意**：`response_description` 用于描述响应，`description` 用于描述路径操作。

**弃用路径操作**：

`deprecated=True`：API 文档标记弃用；

# 中间件

- **本质**：函数；
- **运行时间**：处理**请求**前和返回**响应**前；
- **作用**：类似于**安检机**，对每个请求进入前做一些通用操作，或者对响应返回前做一些通用操作。

## 创建中间件

比如一个计时器中间件：

```python
import time   # 顶部记得 import time

# ===== 中间件：记录每个请求的耗时 =====
@app.middleware("http")
async def log_request_time(request, call_next):
    """每个请求都经过这里：记开始时间 → 放行 → 记结束时间 → 打印耗时"""
    start = time.time()
    response = await call_next(request)    # 放行给后续处理
    duration = time.time() - start
    print(f"[{request.method} {request.url.path}] 耗时 {duration:.3f}s")
    return response
```

**关键**：`await` -> 真正体现了中间件的作用，用于分隔请求进入时的处理和请求完成前。

中间件包裹应用，因此多个中间件最外层先运行（最后声明的，栈式）。
