# 异步

- **同步（sync）**：排队干活；
- **异步（async）**：等待时去干别的；

- `async def`：用了 `await`、异步库（`httpx.AsyncClient`、`AsyncOpenAI`）；
- `def`：用了阻塞库（`requests`、同步 `openai`、`time.sleep`），自动扔入线程池；

**注意**：不要在 `async def` 里用阻塞代码 -> 避免单用户调用时导致其他用户都需等待。

# FastAPI SQL 数据库

## 为什么需要数据库

内存数据:
- 程序关闭会丢失
- 无法多人共享

数据库:
- 持久化保存
- 支持并发访问


## ORM

Object Relational Mapping

作用:

将 Python 对象映射到数据库表，用 `python` 对象操作数据库。

Python 对象 <----> 数据库表


## SQLModel

SQLModel = Pydantic + SQLAlchemy

作用:
- 数据验证
- 数据库映射


## SQLModel 模型

`class User(SQLModel, table=True)`

table=True:
表示该模型对应数据库表


## Field

用于配置字段属性。

primary_key=True:
设置主键
