# 成长足迹

这里记录阶段变化和真实成果，不追求精确到某一天，也不把日常学习写成流水账。早期经历以学期或月份为粒度；从现在开始，再逐渐留下更准确的节点。

## 2025 · 探索与起步

### 10 月

- 建立 CS 自学笔记仓库，开始公开整理 C 语言与计算机基础。

### 11 月

- 完成早期 C 语言通讯录练习，并保留两个版本的迭代记录。

## 2026 · 从笔记走向实践

### 4—5 月

- 跟随教程复现 Streamlit AI 智能伴侣，接触大模型调用、流式输出和本地会话持久化。
- 开始整理 Python、Agent 与 FastAPI 相关知识。
- 基于现有模板建立个人知识库网站，开始持续公开学习记录。

### 6 月

- 建立算法练习仓库，持续记录题目与解法。
- 启动 FastAPI 记账本学习项目。
- 尝试启动 Todo API 项目，当时只完成基础项目骨架。

### 7 月

- 在实习学习记录中接触 Git 协作、Qt 和工程工作流程。
- 继续整理 FastAPI 的依赖注入、异常处理、中间件与数据库知识。

### 9 月

- 重构个人知识库的信息结构、自动侧栏和发布检查流程。
- 完成 FastAPI 记账本的路由拆分、分页、统计图表和前后端单端口整合。
- 创建 `Learning System`，尝试把主动学习、项目实践与复盘方法整理成一组 Codex Skills。该仓库主要通过 vibe coding 完成，目前作为学习方法实验保留。
- 通过 vibe coding 开发个人产品拾光 LearnTrace，发布 `v0.4.0`，并完成 Windows 桌面打包与跨电脑运行验收。

## 记录原则

- 计划不等于完成，尚未实现的内容不会写成成果。
- 教程复现、学习项目、个人产品和独立开发会明确区分。
- AI 完成的实现会如实标注，不把生成代码包装成手写能力。
- 只有重要的开始、完成、第一次和方向变化才进入时间线。

旧的按日期学习内容仍保留在[学习日志归档](/contents/journal/)中，后续会逐步将其中有长期价值的知识整理进[知识库](/contents/notes/)。
