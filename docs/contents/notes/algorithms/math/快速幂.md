# 快速幂

快速幂把指数拆成若干个二的幂，通过不断平方底数，只合并需要的项，避免逐次相乘 `b` 遍。例如：

```text
10 = (1010)₂ = 8 + 2
3¹⁰ = 3⁸ × 3²
```

按二进制从低位到高位处理指数时，当前底数依次为 `A、A²、A⁴、A⁸……`。指数的最低位为 `1`，就把这一项乘入累计答案；随后底数平方、指数右移一位。

## 二进制拆分与循环状态

用 `a` 表示当前底数，`b` 表示尚未处理的指数，`res` 表示已选择项的乘积。忽略取模时，每轮都保持：

```text
res × aᵇ = 原始底数的原始指数次幂
```

若 `b=2k`，有 `aᵇ=(a²)ᵏ`，直接平方底数并将指数减半；若 `b=2k+1`，先把一个 `a` 乘入 `res`，其余同样变成 `(a²)ᵏ`。指数归零后，尚未处理的部分为 `1`，结果全部保存在 `res` 中。

## 模快速幂实现

求 `Aᴮ mod m` 时，可以在每次乘法后取模，因为先对因子取模不会改变整个乘积的余数。循环中对应维护的是上面的同余关系，而不是完整的大整数。

下面从训练文件 `re/math/1.cpp` 提取 `qpow`，保留最终实现并补充步骤注释；不包含同文件中尚未展开的逆元函数。

```cpp
using ll = long long;

// 前提：a、b 非负且可存入 long long；1 <= m <= 1000000000。
ll qpow(ll a, ll b, ll m) {
    a %= m;         // 1. 首次乘法前就把底数缩到合法余数范围。
    ll res = 1 % m; // 2. 空乘积为 1；m=1 时其余数也必须是 0。
    while (b > 0) {
        if (b & 1) res = (res * a) % m; // 3. 当前二进制位为 1，选这一项。
        a = (a * a) % m;               // 4. 准备下一位对应的平方幂。
        b >>= 1;                      // 5. 丢弃已经处理的最低位。
    }
    return res;
}
```

指数大于零时，每轮减半，时间 O(log b)，额外空间 O(1)；指数为零时循环不执行，直接返回初值，耗时为常数。这里按整数乘法、取模为常数时间计，不包含任意精度大整数的运算成本。

## 取模位置、初始化与溢出

`res *= a % m` 等价于 `res = res * (a % m)`，只对乘数取模，不会把整个乘积缩回 `[0,m-1]`。底数更新若写成 `a *= a % m`，也有同样问题。应分别写为 `(res*a)%m`、`(a*a)%m`，不能把赋值运算符当成“乘完再取模”。

例如 `2³ mod 5` 应为 `3`，没有对累计乘积取模时却可能留下完整的 `8`。取模除了影响输出，也用于限制后续乘法的中间值。

- `a%=m` 必须在第一次乘法前执行。即使之后每轮都取模，初始底数过大仍可能让第一次平方或累乘先溢出。
- `b=0` 时，按空乘积为 `1` 的约定返回 `1%m`，包括底数为零的情况。
- `m=1` 时，任何合法余数都为 `0`，所以不能把初始答案固定写成未经取模的 `1`。
- `m=0` 非法，代码不处理负指数，也没有实现负底数的余数归一化。

按这里的范围，`a`、`res` 取模后都小于 `10^9`，乘积小于 `10^18`，可用 `long long` 保存。必须让乘法本身以 64 位进行；先用 `int` 相乘、再赋给 `long long` 来不及补救。若扩大模数范围，普通 64 位乘法未必安全，需要另选模乘方法，不能只沿用 `%m`。

用于检查边界的最小例子：

| a | b | m | 结果 | 检查点 |
|---:|---:|---:|---:|---|
| 2 | 3 | 5 | 3 | 整个乘积取模 |
| 3 | 0 | 7 | 1 | 零指数 |
| 3 | 0 | 1 | 0 | 零指数与模数 1 同时出现 |
