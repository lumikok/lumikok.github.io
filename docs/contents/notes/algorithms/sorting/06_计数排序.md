# 计数排序

计数排序（Counting Sort）是一种**非比较型整数排序算法**。其核心思想是：

1. **统计每个元素出现的次数**：首先遍历输入数组，统计各元素出现次数，并将这些次数存储在一个辅助数组中。
2. **计算元素的正确位置**：通过累加辅助数组中的计数，计算每个元素在排序后数组中的正确位置。
3. **构建排序后的数组**：根据辅助数组中的信息，将元素放置到排序后的数组中。

## 算法实现

### 实现 1：基础计数排序

```cpp
// 计数排序——基础实现(仅处理非负整数)

#include <iostream>
#include <algorithm>
#include <vector>
using namespace std;

void countingSort(vector<int>& arr) {
    if (arr.empty()) return;

    // 1. 找到最大值，确定值域 [0, maxVal]。
    int maxVal = *max_element(arr.begin(),arr.end());

    // 2. count 的长度由值域决定，不是由 arr 的长度决定。
    vector<int> count(maxVal + 1,0);

    // 3. 遍历原数组，统计每个值出现的次数。
    for (int num : arr) {
        count[num]++;
    }

    // 4. 按值从小到大回填原数组。
    int index = 0;
    for (int i = 0; i <= maxVal; i++) {
        while(count[i] > 0) {
            arr[index] = i;
            index++;
            count[i]--;
        }
    }
}
```

### 实现 2：稳定的计数排序

```cpp
// 计数排序——通用实现（可处理负数）

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

void countingSort(vector<int>& arr) {
    if (arr.empty()) return;

    // 1. 找到最大值和最小值，确定完整值域。
    int maxVal = *max_element(arr.begin(),arr.end());
    int minVal = *min_element(arr.begin(),arr.end());

    // 2. 用 num - minVal 将负数也映射到从 0 开始的下标。
    int range = maxVal - minVal + 1;
    vector<int> count(range,0);

    // 3. 遍历原数组，统计各元素出现的次数。
    for (int num : arr) {
        count[num - minVal]++;
    }

    // 4. 计算前缀和。
    // count[i] 表示值小于等于 i + minVal 的元素个数，
    // 也就是该值在输出数组中最后一个位置的下标 + 1。
    for (int i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }

    // 5. 必须逆序遍历“原数组” arr，才能保持相等元素的相对顺序。
    vector<int> output(arr.size());
    for (int i = static_cast<int>(arr.size()) - 1; i >= 0; i--) {
        int index = count[arr[i] - minVal] - 1;
        output[index] = arr[i];
        count[arr[i] - minVal]--;  // 为下一个相同元素预留前一个位置。
    }

    // 6. 将稳定排序结果复制回原数组。
    arr = output;
}
```

## 复杂度与适用场景

设数组长度为 n，值域大小为 k（`maxVal - minVal + 1`）：

- 时间复杂度：O(n + k)。
- 空间复杂度：基础版为 O(k)；稳定版还需要 O(n) 的输出数组。
- 适用场景：键是整数，并且值域相对集中。若 k 远大于 n，计数数组会浪费大量空间，通常不适合使用计数排序。

## 容易混淆的两个长度

- `arr.size()` 是原数组长度，用于遍历待排序元素。
- `range` 是值域长度，用于遍历或分配计数数组。

二者通常不同。稳定回填时若把 `range` 当作原数组长度，可能漏掉元素或访问越界；同时，回填必须从原数组末尾向前进行，不能遍历计数数组来代替。
