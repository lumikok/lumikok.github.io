# 快速排序

快速排序（Quick Sort）是一种高效的排序算法，采用分治法（Divide and Conquer）策略来对数据进行排序。  
其基本思想是通过选择一个“基准”（pivot）元素，将数组划分为两部分，使基准左侧的元素不大于它、右侧的元素不小于它，然后递归地对两部分排序。

## 算法步骤

1. 在当前闭区间 `[left, right]` 中选择基准。
2. 通过左右指针交换元素，使基准移动到最终位置 `pivot`。
3. 递归排序 `[left, pivot - 1]` 与 `[pivot + 1, right]`。
4. 当区间为空或只有一个元素时停止递归。

## 代码实现

```c
void quicksort(int nums[], int left, int right) {
    // 空区间或单元素区间已经有序。
    if (left >= right) {
        return;
    }

    int pivot_value = nums[left];  // 当前实现固定选择首元素为基准。
    int i = left;
    int j = right;

    // 将不大于基准的元素放到左侧，不小于基准的元素放到右侧。
    while (i < j) {
        // 必须先移动右指针，避免覆盖保存在 nums[left] 的基准位置。
        while (i < j && nums[j] >= pivot_value) {
            j--;
        }
        while (i < j && nums[i] <= pivot_value) {
            i++;
        }

        if (i < j) {
            int temp = nums[i];
            nums[i] = nums[j];
            nums[j] = temp;
        }
    }

    // i 与 j 相遇的位置就是基准的最终位置。
    nums[left] = nums[i];
    nums[i] = pivot_value;

    quicksort(nums, left, i - 1);
    quicksort(nums, i + 1, right);
}
```

调用时，`left` 和 `right` 都是合法下标。例如数组长度为 `size`，应调用 `quicksort(nums, 0, size - 1)`。

## 复杂度与稳定性

- 平均时间复杂度：O(n log n)。
- 最坏时间复杂度：O(n²)。当前实现固定选择首元素；当输入已经升序、降序或划分长期极不均衡时，每层可能只排除一个元素。
- 递归栈空间：平均 O(log n)，最坏 O(n)。
- 稳定性：不稳定。分区时的跨区间交换可能改变相等元素的相对顺序。

“输入已经有序”不代表函数会自动停止：除非额外检测，否则它仍会完成分区和递归。随机选择基准、三数取中，或在大量重复元素时使用三路划分，都可以降低退化风险。

## 适用场景

快速排序平均性能好、缓存友好，适合数组的通用内存排序；若必须保证最坏 O(n log n) 或稳定性，应考虑归并排序等方案。
