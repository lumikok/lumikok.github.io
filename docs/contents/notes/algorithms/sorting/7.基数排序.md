# 基数排序

基数排序（Radix Sort）是一种**非比较型整数排序算法**，其与计数排序很相似。其核心思想是：将整数按位数切割成不同的数字，然后按每个位数分别比较。基数排序通常使用**LSD（Least Significant Digit）**或**MSD（Most Significant Digit）**两种方法进行排序。

## 算法原理

### 主要步骤

1. **确定最大数字的位数**：找到数组中最大数的位数，从而确定需要进行多少轮排序。
2. **按位排序**：LSD 从个位开始，依次处理十位、百位等位置。
3. **保持每一轮稳定**：同一位数字相等的元素必须保持上一轮的相对顺序，否则前面已经排好的低位会被破坏。

### 稳定性

基数排序可以实现为稳定排序。前提是每一位使用的内部排序也稳定；下面使用稳定的计数排序。

### 时间复杂度

时间复杂度：O(d * (n + k))

- d：最大数字的位数（排序轮数）
- n：数组长度
- k：每个位数的取值范围（对于十进制数，k=10）

## 算法实现

```cpp
#include <algorithm>
#include <stdexcept>
#include <vector>
using namespace std;

// 按 exp 对应的数位进行一次稳定计数排序。
// exp = 1、10、100 时分别表示个位、十位、百位。
void counting_sort_by_digit(vector<int>& arr, long long exp) {
    vector<int> count(10, 0);
    vector<int> output(arr.size());

    // 1. 统计当前数位 0～9 出现的次数。
    for (int num : arr) {
        int digit = static_cast<int>((num / exp) % 10);
        count[digit]++;
    }

    // 2. 转为前缀和，得到每个数位在输出数组中的结束位置。
    for (int digit = 1; digit < 10; digit++) {
        count[digit] += count[digit - 1];
    }

    // 3. 逆序遍历原数组，保证本轮排序稳定。
    for (int i = static_cast<int>(arr.size()) - 1; i >= 0; i--) {
        int digit = static_cast<int>((arr[i] / exp) % 10);
        output[count[digit] - 1] = arr[i];
        count[digit]--;
    }

    // 4. 将本轮结果复制回原数组，供下一数位继续排序。
    arr = output;
}

void radix_sort(vector<int>& arr) {
    if (arr.empty()) {
        return;
    }

    // 该基础实现只处理非负整数。
    if (*min_element(arr.begin(), arr.end()) < 0) {
        throw invalid_argument("radix_sort only supports non-negative integers");
    }

    int max_value = *max_element(arr.begin(), arr.end());

    // 从低位到高位逐轮排序；long long 可避免 exp *= 10 时溢出 int。
    for (long long exp = 1; max_value / exp > 0; exp *= 10) {
        counting_sort_by_digit(arr, exp);
    }
}

```

## 适用场景与边界

- 适合位数有限、数据量较大的非负整数或固定长度字符串。
- 上面的基础实现不直接支持负数；若要支持，需要单独处理符号与绝对值，不能直接拿负数数位作为计数数组下标。
- 当数据规模较小或位数很多时，多轮扫描和额外数组可能不划算。
