# 冒泡排序

## 简单介绍

冒泡排序（Bubble Sort）是一种简单的排序算法。通过连续地比较与交换相邻元素，将较大的元素逐渐“冒泡”到序列的末端，从而实现排序。

## 算法流程

1. 从左到右比较相邻元素，若前者较大就交换。
2. 一轮结束后，当前未排序区间中的最大值会移动到区间末尾。
3. 缩小未排序区间并重复；若某一轮没有发生交换，说明数组已经有序，可以提前结束。

## 代码实现

```c
#include <stdio.h>

void bubble_sort(int arr[], int size) {
    // 每轮结束后，[end, size) 已经有序。
    for (int end = size - 1; end > 0; end--) {
        for (int j = 0; j < end; j++) {
            // 只在前一个元素更大时交换，相等时不交换，从而保持稳定性。
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
}
```

## 优化

可以发现，有些时候是不需要比较所有元素的，因此可以引入一个`flag`变量来检测在某一轮比较中是否发生了交换操作。如果没有发生交换，说明数组已经有序，可以提前结束排序。

```c
void bubble_sort(int arr[], int size) {
    for (int end = size - 1; end > 0; end--) {
        int swapped = 0;

        // 只扫描未排序区间 [0, end]。
        for (int j = 0; j < end; j++) {
            if (arr[j] > arr[j + 1]) {
                int temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
                swapped = 1;
            }
        }

        // 本轮没有交换，说明整个数组已经有序。
        if (!swapped) {
            break;
        }
    }
}
```

## 复杂度分析

- 时间复杂度：平均和最坏情况为 O(n²)；加入提前结束后，最好情况为 O(n)。
- 空间复杂度：O(1)，属于原地排序。
- 稳定性：稳定。代码只在 `arr[j] > arr[j + 1]` 时交换，相等元素不会互换。
- 适用场景：数据量较小或数据接近有序，并且希望实现简单、保持稳定性。
