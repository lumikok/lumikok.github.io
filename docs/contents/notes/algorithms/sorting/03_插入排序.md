# 插入排序

插入排序（Insertion Sort）是一种简单的排序算法，它的工作原理类似于我们整理扑克牌手牌的方式。在未排序部分中找一个基准元素，对已排序部分从后向前扫描，找到合适的位置插入该基准元素。重复此过程，直到所有元素均排序完毕。

## 算法步骤

1. 从数组的第二个元素开始，假设第一个元素已经排序。
2. 取出当前元素（称为“基准”）。
3. 将基准与已排序部分的元素进行比较，从后向前扫描已排序部分。
4. 如果已排序部分的元素大于基准，则将该元素向后移动一位。
5. 重复步骤4，直到找到合适的位置插入基准。
6. 将基准插入到找到的位置。
7. 重复步骤2-6，直到整个数组排序完成。

## 代码实现

```c
#include <stdio.h>

void insert_sort(int arr[], int size) {
    // 每轮开始时，[0, i) 已经有序。
    for (int i = 1; i < size; i++) {
        int base = arr[i];
        int j = i - 1;

        // 将所有大于 base 的元素右移，为 base 腾出位置。
        while (j >= 0 && arr[j] > base) {
            arr[j + 1] = arr[j];
            j--;
        }

        // 循环结束时，j == -1 或 arr[j] <= base，插入位置是 j + 1。
        arr[j + 1] = base;
    }
}
```

## 复杂度分析

- 时间复杂度：平均和最坏情况为 O(n²)，最好情况为 O(n)（数组已经有序）。
- 空间复杂度：O(1)，属于原地排序。
- 稳定性：稳定。循环只移动严格大于 `base` 的元素，相等元素的相对顺序不变。
- 适用场景：数据量较小或接近有序；也常用于优化其他排序算法中的小规模子区间。
