# 欧拉回路

## 什么是欧拉回路

> **经过图中每一条边恰好一次，并最终回到起点的路径**。

**注意**：是**每条边一次**，而非**点**；并且需要回到起点，不回到起点的是**欧拉路**。因此，欧拉回路**允许经过同一点多次，不重边即可**。

## 判断条件

1. **欧拉回路**：欧拉回路中的所有顶点度数都是**偶数**；
2. **欧拉路**：恰好两个奇数度顶点。

**注意为充要条件**。

## 怎么找

在连通图中寻找欧拉回路，可通过**Hierholzer 算法（希尔霍泽算法）**。

**核心逻辑**：

1. 从起点出发，任意选择一条边，并删掉这条边（标记 used）；
2. 走到无法再走下去，即没有其他边可走的结点；
3. 此时，一定形成了“环”，记录下来该环；
4. 回溯到上一个有边可走的结点，将其形成的环插入到之前那个环；
5. 把所有环拼接起来即可。

**代码实现**：

```cpp
void dfs(int u) {
	while(!g[u].empty()) {
		int v = g[u].back();
		g[u].pop_back();
		
		if(used[id]) continue;
		
		used[id] = true;
		
		dfs(v);
	}
	ans.push_back(u);
}
```

**注意**：答案是在回溯时加入的，不是在进入结点的时候
