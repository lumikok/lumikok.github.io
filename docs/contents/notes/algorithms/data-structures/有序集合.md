# 有序集合与邻居查询

需要动态插入、删除，并查询某个值左右最近的元素时，可以使用 `set<int>`。默认按整数升序排列，同一个值只保存一次；它维护的是值的次序，不是元素的输入顺序。

`unordered_set` 适合判断某个键是否存在，但不提供按数值寻找前驱、后继的接口。若问题依赖“最近的较小值”或“第一个更大值”，只记录存在性还不够，不应因为两者都叫集合就互换。

## lower_bound、upper_bound 与合法迭代器

| 调用 | 升序 `set<int>` 中的含义 |
|---|---|
| `s.lower_bound(x)` | 第一个大于或等于 `x` 的位置 |
| `s.upper_bound(x)` | 第一个严格大于 `x` 的位置 |
| `s.insert(x)` | 插入 `x`，重复值不新增元素 |
| `s.erase(x)` | 删除值为 `x` 的元素；不存在则不删除 |

查不到符合条件的元素时，查找返回 `end()`，它不能解引用。求某迭代器的前一个位置前，要先确保它不是 `begin()`；非空集合才可以对 `end()` 使用 `prev` 取得最后一个元素。`prev` 需要 `<iterator>`。

这些成员查找、普通插入及按键删除的复杂度为 O(log k)，`k` 为当前集合规模；沿一个迭代器向前一步不需要重新搜索整棵树。插入不使已有元素的迭代器失效，删除则会使被删元素的迭代器失效。语义与界限见 [C++ 关联容器规范](https://eel.is/c++draft/associative.reqmts)。

## 最近值只需比较两侧候选

对目标 `x`，令 `right=lower_bound(x)`。若它存在，就是所有不小于 `x` 的值中最近的一个；若它之前还有元素，`prev(right)` 就是所有小于 `x` 的值中最近的一个。同一侧再远的值不会更优，因此只需比较这两个候选，而不是扫描整个集合。

下面整理自 [P5250 木材仓库](https://www.luogu.com.cn/problem/P5250) 的训练源码 `01_date/2026-10/P5250.cpp`，只提取“非空库存中取走最近值”部分为函数，保留原边界分支、同距离取较小值和按值删除。外层空集合应先输出 `Empty`，成功插入不输出，重复进货才输出 `Already Exist`。

```cpp
#include <iterator>
#include <set>
using namespace std;

// 前提：stock 非空；目标和库存值均在 [1,1000000000] 内。
int takeNearest(set<int>& stock, int length) {
    auto right = stock.lower_bound(length); // 1. 找右侧最近候选（包含恰好相等）。
    int chosen;
    if (right == stock.end()) {
        chosen = *prev(right); // 全部小于目标，取最大值；非空保证可向前走。
    } else if (right == stock.begin()) {
        chosen = *right;       // 没有左侧候选，直接取当前值。
    } else {
        auto left = prev(right);
        // 2. 两侧都有候选；相等距离时取较小者。
        chosen = (length - *left <= *right - length) ? *left : *right;
    }
    stock.erase(chosen); // 3. 出货后更新库存，不能在后续查询中再次选到它。
    return chosen;
}
```

库存 `{5,15}`、目标 `10` 时取走 `5`，随后库存只剩 `{15}`。插入两个相同长度不会产生两份库存；如果另一个问题需要保存重复元素，就必须重新选择表示，不能直接依赖 `set` 去重。

## 维护断点，而不是反复扫描连续段

另一种邻居查询发生在位置序列中：保存所有零的位置，某个仍为一的位置 `i` 左右最近的零 `L、R` 就框定了它所在的连续一段，长度为 `R-L-1`。关闭 `i` 时，把它加入断点集合；后续查询自动使用新的邻居。

在实际范围 `1..n` 两侧加入虚拟零位置 `0、n+1`，可以让首尾段也存在左右边界。哨兵不是永远正确的“补丁”：必须明确它在模型中代表什么，并保证它不会被当成真实位置计入长度。

与木材库存不同，断点只需记录出现过的位置，并不保存重复次数。具体关停规则、一次关闭如何拆段、重复关闭以及累计范围见[月赛 C：用零断点维护连续段](../../../problems/ordered-set.md)。
