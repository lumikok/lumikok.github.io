# 队列

队列是一种遵循先进先出规则的线性数据结构。它就类似于排队的情况。

## 队列的实现

### 链表

非空队列的 `front` 指向队首、`rear` 指向队尾；空队列的两个指针都为 `NULL`。入队连接队尾，出队移除队首，均为 O(1)。下面用返回值表示操作是否成功，避免把某个合法整数当作“空队列”标记。除析构允许传入 `NULL` 外，操作函数要求传入有效队列；读取结果的 `out` 也必须是有效指针。

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

typedef struct ListNode {
    int data;
    struct ListNode *next;
} ListNode;

typedef struct {
    ListNode *front,*rear;
    int size;
} LinkedListQueue;

// 构造函数

LinkedListQueue *initqueue(void) {
    LinkedListQueue *queue = malloc(sizeof *queue);
    if (queue == NULL) {
        return NULL;
    }
    queue->front = NULL;
    queue->rear = NULL;
    queue->size = 0;
    return queue;
}

// 析构函数

void freequeue(LinkedListQueue *queue) {
    if (queue == NULL) {
        return;
    }
    // 先释放全部节点，再释放队列对象本身。
    while (queue->front != NULL) {
        ListNode *temp = queue->front;
        queue->front = queue->front->next;
        free(temp);
    }
    free(queue);
}

// 获取队列长度

int size(const LinkedListQueue *queue) {
    return queue->size;
}

// 判断是否为空

bool isempty(const LinkedListQueue *queue) {
    return queue->size == 0;
}

// 入队

bool push(LinkedListQueue *queue, int data) {
    // 1. 分配失败时保持原队列不变。
    ListNode *newnode = malloc(sizeof *newnode);
    if (newnode == NULL) {
        return false;
    }
    newnode->data = data;
    newnode->next = NULL;

    // 2. 空队列同时设置首尾；非空队列把新节点接到队尾。
    if (queue->front == NULL) {
        queue->front = newnode;
        queue->rear = newnode;
    }
    else {
        queue->rear->next = newnode;
        queue->rear = newnode;
    }
    queue->size++;
    return true;
}

// 出队

bool pop(LinkedListQueue *queue, int *out) {
    // 1. 空队列没有可访问的队首，先判断再解引用。
    if (isempty(queue)) {
        return false;
    }
    ListNode *temp = queue->front;
    *out = temp->data;

    // 2. 前移队首并释放旧节点。
    queue->front = queue->front->next;
    free(temp);
    queue->size--;

    // 3. 最后一个节点出队后，队尾也必须清空。
    if (queue->front == NULL) {
        queue->rear = NULL;
    }
    return true;
}

// 访问队首元素

bool peek(const LinkedListQueue *queue, int *out) {
    if (isempty(queue)) {
        return false;
    }
    *out = queue->front->data;
    return true;
}

// 顺序遍历即可打印，不需要额外复制到数组。

void print(const LinkedListQueue *queue) {
    printf("队列元素：");
    for (const ListNode *current = queue->front; current != NULL;
         current = current->next) {
        printf("%d ", current->data);
    }
    printf("\n");
}
```

使用时先检查 `initqueue()` 是否返回 `NULL`；`push` 失败时不能假定元素已经入队。`pop`、`peek` 仅在返回 `true` 时写入结果，失败时保持 `*out` 不变。调用 `freequeue` 后原指针失效，不应再访问它。

### 数组实现要点

循环数组可以用 `front` 和 `size` 维护队列。容量 `capacity` 必须为正：入队位置是 `(front + size) % capacity`；出队后令 `front = (front + 1) % capacity` 并减少长度。通过 `size == 0` 和 `size == capacity` 分别判断空、满，读写前先检查对应条件，无需每次出队都搬动其余元素。

## 边界由每轮动作自然覆盖

P1996 中每轮应“移动 `m-1` 次，再淘汰当前元素”。`m >= 1` 时可以直接按这个次数写循环，`m=1` 就是移动零次。先固定移动一次再补判断，会使最小输入偏离同一套计数规则。

应检查 `m=1` 时能否正常淘汰并终止；同类边界检查见[二分查找插入点](../../searching/2.二分查找插入点.md)。

## 两种结构各管一件事：FIFO 缓存

P1540 的关键需求有两个：缓存满时淘汰最早进入的元素，以及判断某个元素是否已在缓存中。队列适合前者；成员查询可以交给布尔表或集合。

设有 `n` 次请求，容量为 `m >= 1`，维护两个约定：队列中的先后顺序就是淘汰顺序；成员表恰好包含队列中的元素，每个元素只存一份。

```text
若成员表中已有 x：直接命中，保持队列顺序
否则：
    若队列已满：取出队首 old，并从成员表删除 old
    将 x 放到队尾，并在成员表中标记 x
```

命中时不把元素移到队尾，因为这里按进入时间淘汰；删除、入队时要同步维护成员表，否则两个结构会出现矛盾。

- 轮转队列查找：每次最多扫描 `m` 个元素，总时间 O(nm)。轮转后还必须恢复原来的顺序，否则会改变下一次淘汰对象。
- 布尔表：若值域大小为 `U`，初始化 O(U)，处理请求 O(n)，总时间 O(U+n)，额外空间 O(U+m)。适合值域可直接映射且大小可接受的情况。
- 哈希集合：成员查询通常为期望 O(1)，总时间期望 O(n)，额外空间 O(m)。
- 有序集合：单次操作 O(log m)，总时间 O(n log m)（容量为 1 时按常数计算），额外空间 O(m)。不能把所有“集合”都当成常数时间查询。
