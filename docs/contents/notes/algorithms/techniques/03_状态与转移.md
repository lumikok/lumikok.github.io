# 状态与转移

状态应保留决定后续行为的信息。判断一份状态是否够用，可以问：两段历史如果留下了相同状态，接下来可做的动作、下一状态和新增代价是否相同？若仍要翻查被省略的历史，状态就缺少信息。

## 模拟：完整状态相同，后续过程才相同

在 P1518 的固定地图上，两方的行动由各自位置和朝向决定。因此联合状态是：

```text
(农夫行, 农夫列, 农夫方向, 牛行, 牛列, 牛方向)
```

只记两方的位置不够：同一位置朝向不同，下一分钟的行动可能不同。只判断某一方是否重复也不够：另一方可能处在不同位置或方向，整个系统还没有重复。

地图和规则固定时，相同联合状态只有同一个后继。若尚未相遇就回到一个已访问状态，以后也只会重复已经走过的过程，可以据此判定无法相遇。

若规则改为随分钟奇偶变化，即使双方位置与方向相同，下一步也可能不同。这时状态还需要包含 `时间 % 2`。原题规则不随时间变化，所以不必保存绝对时间；分钟数可以作为答案计数，而不作为判重维度。具体推进与边界见[P1518 状态模拟题解](../../../problems/simulation.md)。

## 最优化：相同状态下，只保留有用的历史

Frog 问题中，到达同一块石头后，下一步能跳哪里、需要增加多少费用，都由当前位置和固定高度决定，与之前走过的路线无关。

因此，到达第 `i` 块石头的多条路线只需保留其中最小总代价，记为 `dp[i]`。任何更贵的路线继续走同一段后续，都不会优于较便宜的路线。这里 `i` 是状态下标，最小总代价是该状态保存的值，不需要另开一维枚举所有已有花费。

若题目加入“剩余体力决定能否继续跳”之类规则，仅有当前位置可能不够，必须重新检查需要保存的信息，不能直接套用原状态。

## 按最后一步分类推导转移

计算某个状态的最优值时，枚举所有能到达它的前驱：

```text
候选代价 = 到达前驱的最优代价 + 最后一步代价
当前最优值 = 所有合法候选中的最小值
```

Frog 1 的最后一跳只能来自前一块或前两块；Frog 2 改为前 `K` 块。推广时变化的是前驱范围，状态含义和“前驱最优值加一步代价”的结构不变。

实现前还要确定：起点值、其他状态的最小值初始化、合法前驱下标，以及依赖状态是否已算出。Frog 的前驱编号都小于当前编号，所以可从左到右计算；具体公式、实现与边界见[Frog 1→2 题解](../../../problems/dynamic-programming.md)。

## 预算状态：二维 01 背包

[P1048 采药](https://www.luogu.com.cn/problem/P1048) 中，每株草药有耗时和价值，每株至多采一次，在总时间 `T` 内最大化价值。这里不仅要知道考虑到了第几株，还要知道可用的时间预算：

`dp[i][j]` 表示只考虑前 `i` 株、总耗时**不超过** `j` 时的最大价值。

`j` 是预算上限，不是已经花掉的时间，也不是“必须恰好用完 j”。比如预算为 `5`，只有耗时 `3`、价值 `4` 的一株草药，答案仍为 `4`，不要求填满剩余时间。

按是否选择第 `i` 株分类：

```text
不选：dp[i-1][j]
选择：dp[i-1][j-cost[i]] + value[i]   // 仅在 j >= cost[i] 时合法
dp[i][j] = 两类合法候选的最大值
```

两类候选都读取上一行。选择当前草药后，剩余预算只能交给前 `i-1` 株处理，当前这株不会再次出现；如果误读本行 `dp[i][j-cost[i]]`，在从小到大枚举预算时，就可能重复使用同一株。

### 初值来自状态含义

没有草药时，不论预算是多少，都能选择空方案，价值为 `0`，所以 `dp[0][j]=0`。在本题“可以不选、耗时不超过上限”的含义下，全表从零开始，再逐行取最大值是成立的；耗时均为正，因此预算为零时也只能不选。

若状态改为“恰好耗时 j”，没有草药却要耗时大于零的状态就是不可达，不能仍把它当成价值为零的合法方案。这个区别用于检查初始化前提，不把当前实现直接当成另一种模型的模板。

下面从训练文件 `01_date/2026-10/P1048.cpp` 提取二维实现为函数，保留 `1` 起始数组、全零初值、上一行依赖和时间不足时的继承；没有改成一维压缩。

```cpp
#include <algorithm>
#include <vector>
using namespace std;

// cost[0]、value[0] 为占位；其余元素对应每株草药。
// 前提：两个数组等长且至少有一株；预算非负，耗时与价值均为正。
// 数值范围沿用 P1048：M<=100、T<=1000，单株耗时与价值<=100。
int maxHerbValue(int budget, const vector<int>& cost, const vector<int>& value) {
    int m = static_cast<int>(cost.size()) - 1;
    vector<vector<int>> dp(m + 1, vector<int>(budget + 1, 0));
    for (int i = 1; i <= m; ++i) {
        for (int j = 0; j <= budget; ++j) {
            dp[i][j] = dp[i - 1][j]; // 1. 不选当前株，继承上一行。
            if (j >= cost[i]) {
                // 2. 选当前株；剩余预算仍只允许使用前 i-1 株。
                dp[i][j] = max(dp[i][j], dp[i - 1][j - cost[i]] + value[i]);
            }
        }
    }
    return dp[m][budget]; // 3. 读全部草药、完整预算下的最优值。
}
```

预算 `5`、草药 `(耗时,价值)` 为 `(3,4)、(2,3)、(4,6)` 时，前两株合计价值为 `7`。另一个用于区分次数限制的例子是：预算 `6`、只有 `(3,4)` 一株时，01 模型答案为 `4`，不是 `8`。

共计算 `(M+1)×(T+1)` 个状态，每个状态只比较常数个候选，时间、空间均为 O(MT)。不能因为一次转移是常数时间，就把整张表的计算也算成 O(1)。
