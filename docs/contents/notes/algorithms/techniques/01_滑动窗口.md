# 滑动窗口

滑动窗口用左右端点维护一个连续区间。右端扩张后更新状态，区间不合法时右移左端，再用合法区间更新答案。能否让左端只向右移动，要从约束的单调性说明。

## 区间和受限：为什么左端不需要回退

[CF279B Books](https://codeforces.com/problemset/problem/279/B) 要找耗时不超过预算的最长连续段，耗时为正数。固定左端时，扩张右端不会使区间和减小；若某个左端已经导致超限，以后再扩张右端也无法救回它，因此可以永久排除这个左端。

下面从训练文件 `01_date/2026-10/CF279B.cpp` 提取窗口逻辑，整理成接收已读入数组的函数。原文件边输入边维护窗口；两种读入方式都适用于本题。

```cpp
#include <algorithm>
#include <vector>
using namespace std;

// 前提：耗时非负，budget >= 0。
int maxBooks(const vector<int>& a, long long budget) {
    int left = 0;
    int best = 0;
    long long sum = 0;

    for (int right = 0; right < static_cast<int>(a.size()); ++right) {
        sum += a[right];  // 1. 扩张右端，将新元素计入状态。

        // 2. 超限就收缩；单个元素超限时允许窗口缩为空。
        while (left <= right && sum > budget) {
            sum -= a[left];
            ++left;
        }

        // 3. 此时 [left, right] 合法，长度可能为 0。
        best = max(best, right - left + 1);
    }
    return best;
}
```

若允许负数，上述排除依据就不成立。例如 `[4, -3]`、预算 `1`：读到 `4` 时移除它，之后便会错过和为 `1`、长度为 `2` 的整个区间。

## 排序后的窗口：合法范围与收益要分别判断

[CF580B Kefa and Company](https://codeforces.com/problemset/problem/580/B) 按金钱排序后，用 `money[right] - money[left] < d` 判断区间是否合法。右端向右时金钱不减，曾经差值过大的左端不会重新合法，因此左端可以持续右移。

但这只说明哪些人可以一起选。还需要友情值非负，才能保证把合法范围中的人全部选上不会降低总收益，所以存在一个最优解对应排序后的完整连续区间。若友情值允许为负，金钱差的窗口仍可维护，但“取整个合法窗口的收益和”可能错过跳过负收益者的更优选择。

两题中非负条件支持的步骤不同：

| 问题 | 非负条件支持什么 |
| --- | --- |
| Books 的耗时 | 扩右端不会减小区间和，超限后可排除旧左端 |
| Kefa 的友情值 | 合法范围内补选中间的人不会损失收益 |

Kefa 的左端单调性来自按金钱排序，不能把它归因于友情值非负。具体实现见[滑动窗口题解](../../../problems/sliding-window.md)。

## 嵌套循环为什么仍是 O(n)

右端从头到尾移动 `n` 次，左端也最多移动 `n` 次。虽然收缩写在内层 `while` 中，但左端从不回退，所有收缩合起来只有 O(n) 次。每次状态更新为 O(1)，扫描总时间就是 O(n)，而不是 O(n²)。

若先排序再扫描，要把排序的 O(n log n) 加进去。Books 的训练实现保存数组，空间为 O(n)；不能因为只有两个指针就把整个程序的额外存储写成 O(1)。

## 用 pair 保持两个字段的对应

Kefa 中金钱和友情值属于同一个人，排序时必须一起移动：

```cpp
#include <utility>
vector<pair<long long, long long>> people; // {money, friendship}
// 读入后使用 sort(people.begin(), people.end())。
```

`pair` 可以作为容器元素；默认比较先看 `first`，相等时再看 `second`，因此默认排序并非只比较第一个字段。这里同金钱者内部的次序不影响合法性和总收益。参见 [C++ pair 比较规则](https://eel.is/c++draft/pairs.spec)。

若 `pre[i]` 表示前 `i` 人的友情值总和，则闭区间 `[left, right]` 的收益是 `pre[right + 1] - pre[left]`。排序与前缀和必须使用同一份顺序；不要分别排序两个字段。前缀和的通用原理见[前缀和](preprocessing/01_%E5%89%8D%E7%BC%80%E5%92%8C.md)。
