# 前缀和与差分的联系

差分记录相邻位置的变化，前缀累计把变化还原成实际值。采用从 `1` 开始的下标，约定 `a[0] = 0`：

```text
diff[i] = a[i] - a[i-1]
a[i] = diff[1] + ... + diff[i]
```

这与“对原数组建立前缀和，再查询区间和”要区分：前者累计差分以还原元素值，后者用两个前缀和相减得到区间总和。基础公式见[前缀和](01_前缀和.md)和[差分](02_差分.md)。

## 两种索引空间

如果一批请求指定“执行第 `x` 到第 `y` 条操作”，而每条操作又指定“给原数组第 `l` 到第 `r` 个元素加 `d`”，需要先分清两层下标：

| 数组 | 下标表示什么 | 累计后得到什么 |
| --- | --- | --- |
| `opDiff` | 操作编号，范围 `1..m` | `cnt[i]`：第 i 条操作执行的次数 |
| `diff` | 原数组位置，范围 `1..n` | 每个位置最终的值，或该位置的总增量 |

`x、y` 只能用于更新操作次数；`l、r` 才对应原数组位置。`m` 与 `n` 可以不同，不能因为两次都用差分，就共用同一个数组或循环上界。

## 先累计次数，再加权更新

1. 把每条操作的 `l、r、d` 存起来，暂不反复执行。
2. 对每个请求 `[x,y]`，令 `opDiff[x] += 1`、`opDiff[y+1] -= 1`。
3. 对 `opDiff` 做前缀累计，得到全部 `cnt[i]`。
4. 第 i 条操作累计贡献为 `cnt[i] × d[i]`，把它一次性加到原数组的 `[l[i],r[i]]`：在 `diff[l[i]]` 加上贡献，在 `diff[r[i]+1]` 减去贡献。
5. 对原数组位置上的 `diff` 做前缀累计，得到最终结果。

可以合并执行次数，是因为这些操作都做加法，结果可按贡献叠加，执行先后不改变最终值。若操作包含赋值等依赖顺序的行为，就不能直接套用“先计次数再合并”的处理。

## 加权请求例子

下面来自训练文件 `re/diff/1.cpp` 的加权变式：请求 `[x,y,w]` 表示区间中的每条操作各执行 `w` 次。此时只需把第一层端点的 `+1/-1` 换成 `+w/-w`。

原数组为 `[5,0,1,2]`，有三条操作：

| 操作编号 | 原数组区间 | 每次增加 |
| --- | --- | --- |
| 1 | [1,3] | 2 |
| 2 | [2,4] | 1 |
| 3 | [4,4] | 100 |

三个加权请求为 `[1,2,2]`、`[2,2,3]`、`[1,1,1]`。在操作编号空间累计：

```text
opDiff[1..4] = [3, 2, -5, 0]
cnt[1..3]    = [3, 5, 0]
```

因此第一条操作向原数组 `[1,3]` 加 `6`，第二条向 `[2,4]` 加 `5`，第三条没有执行。各位置总增量为 `[6,11,11,5]`，最终得到 `[11,11,12,7]`。操作上的区间 `[1,2]` 不等于原数组上的区间 `[1,2]`。

## 初始化决定还原结果的含义

有两种一致的写法，不能混着用：

| 初始化方式 | 累计后的含义 | 最后如何得到答案 |
| --- | --- | --- |
| `diff[i] = a[i] - a[i-1]` | 已含原值的最终数组 | 累计结果直接作为答案 |
| `diff` 全部初始化为 0 | 所有操作带来的总增量 | 累计结果再加原来的 `a[i]` |

只看位置 `1..4`，上例原数组差分为 `[5,-5,1,1]`，所有更新带来的差分变化为 `[6,5,0,-6]`；相加得 `[11,0,1,-5]`，前缀累计便是最终数组。若此后再加一次原数组，就会重复计入初值。

## 边界、数值范围与复杂度

- 第一层要访问 `y+1`，用长度为 `m+2` 的数组；第二层要访问 `r+1`，用长度为 `n+2` 的数组。末端后一格用于抵消影响，不作为答案输出。
- 操作次数为零时，该条操作贡献也为零；单点区间仍使用同一套端点公式。
- 次数、累计增量和最终值都可能超过 `int`。让乘法的操作数使用 `long long`，避免先以 `int` 溢出后才赋给更宽类型。
- `k` 个请求只改两端，O(k)；累计操作次数和合并操作各 O(m)，最终还原 O(n)。总时间 O(n+m+k)。按请求边读边更新时，额外空间为 O(n+m)。
