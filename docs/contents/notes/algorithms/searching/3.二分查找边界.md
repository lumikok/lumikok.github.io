# 二分查找边界

查找相同元素的边界，可以先找插入点，再判断该位置是否真的等于目标。这里仍采用闭区间 `[left, right]`，数组已按升序排列。

## 左边界：第一个等于目标的位置

先找第一个大于或等于 `target` 的位置，也就是 `lower_bound`；该位置可能等于数组长度，也可能指向比目标更大的元素，因此还需要检查是否命中。

```c
#include <stdio.h>

int binarySearchFirstEqual(const int arr[], int size, int target) {
    int left = 0;
    int right = size - 1;

    // 第一步：寻找第一个 >= target 的位置。
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] >= target) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }

    // 第二步：插入点不一定是实际命中；先查边界，再读取数组。
    return left < size && arr[left] == target ? left : -1;
}
```

只有第一步与查找最左插入点相同。若直接返回 `left`，函数表达的是插入点，不能称为“第一个等值元素”。

## 右边界：最后一个等于目标的位置

先找第一个严格大于 `target` 的位置，也就是 `upper_bound`；它前面的元素才可能是最后一个目标值。

```c
int upperBound(const int arr[], int size, int target) {
    int left = 0;
    int right = size - 1;

    // 寻找第一个 > target 的位置，找不到时返回 size。
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (arr[mid] > target) {
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }
    return left;
}

int binarySearchLastEqual(const int arr[], int size, int target) {
    int pos = upperBound(arr, size, target) - 1;
    if (pos < 0 || arr[pos] != target) {
        return -1;
    }
    return pos;
}
```

这里不能用 `lower_bound(target + 1)` 替代 `upper_bound(target)`：若 `target` 是整数类型的最大值，`target + 1` 会溢出。

## 检查边界时问自己

1. `mid` 是否由当前 `left` 和 `right` 计算？曾漏掉 `left`，使搜索无法随区间变化。
2. 每一轮是否严格缩小闭区间？更新时要排除已经判断过的 `mid`。
3. 返回的是插入点还是实际等值位置？读取数组前是否确认下标合法？
4. 空数组、目标不存在、所有元素相等、目标只在末尾时，返回值是否符合定义？
