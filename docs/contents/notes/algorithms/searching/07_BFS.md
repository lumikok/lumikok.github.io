# 广度优先搜索

BFS 用先进先出的队列逐层扩展状态。每次转移代价相同、只求最少步数时，可以把状态看作顶点、一次操作看作一条边；图不必提前存成邻接表，网格和整数操作都可以在出队后生成后继。

## 为什么首次到达就是最短距离

起点距离为 `0`。处理距离为 `d` 的状态时，把尚未访问的后继标为 `d+1` 并放到队尾。队列中距离为 `d` 的状态会先于新加入的 `d+1` 层处理，因此出队距离单调不减。

如果存在一条更短的路线，它的前驱应在更早的层中处理，目标也应更早被发现，与“当前才首次到达”矛盾。因此在等代价转移下，第一次发现某状态就能确定其最短距离。

这个结论依赖每步代价相同；边权不同时，不能只凭首次访问就把距离定死。普通 DFS 的首次到达也不保证最短，因为它可能先走完一条较长路线。

## 入队前标记，距离兼任访问标记

用 `dist=-1` 表示未访问，起点设为 `0`。生成后继时依次处理：

1. 检查后继是否合法，再访问对应的数组元素。
2. 跳过已访问状态。
3. 写入 `dist[next]=dist[cur]+1`，然后入队。

标记应在入队前完成。如果等到出队才标记，同一层的多个前驱可能把相同后继重复加入队列。提前标记使每个状态至多入队一次，既避免重复扩展，也让距离与访问状态保持一致。

求某个目标时，可以在首次发现目标或目标出队时结束；求所有状态的距离时，则应继续处理到队列为空。不可达状态最终仍为 `-1`。

## 多源 BFS：把所有起点放在第零层

目标若是“到任意一个起点的最短距离”，先将所有不同起点的距离设为 `0` 并入队，再启动同一个 BFS。不同起点在同一队列中逐层扩散，首次到达某点的那一层就是它到最近起点的距离。

不能先让一个起点传播完，再加入另一个起点，却仍用“访问过就跳过”的逻辑：第一个起点写下的距离可能不是最近距离，后面的起点已经无法修正。

下面从训练文件 `01_date/2026-10/P1332.cpp` 提取并整理为函数：把全局数组改为局部二维数组，保留原实现的四方向扩展、源点去重和入队前标记。坐标从 `1` 开始，所有格子都可通行；它不是带障碍迷宫的完整输入程序。

```cpp
#include <queue>
#include <utility>
#include <vector>
using namespace std;

// 前提：n、m >= 1；所有源点都在 [1,n] × [1,m] 内。
vector<vector<int>> nearestSourceDistances(
    int n, int m, const vector<pair<int, int>>& sources) {
    vector<vector<int>> dist(n + 1, vector<int>(m + 1, -1));
    queue<pair<int, int>> q;

    // 1. 先放入全部零距离源点，重复坐标只入队一次。
    for (const auto& source : sources) {
        int x = source.first, y = source.second;
        if (dist[x][y] != -1) continue;
        dist[x][y] = 0;
        q.push({x, y});
    }

    const int dx[] = {0, 1, 0, -1};
    const int dy[] = {1, 0, -1, 0};
    while (!q.empty()) {
        int x = q.front().first, y = q.front().second;
        q.pop();
        for (int k = 0; k < 4; ++k) {
            int nx = x + dx[k], ny = y + dy[k];
            // 2. 先判坐标合法，避免用越界下标查询 dist。
            if (nx < 1 || nx > n || ny < 1 || ny > m) continue;
            if (dist[nx][ny] != -1) continue;
            // 3. 首次到达就确定距离，并在入队前标记。
            dist[nx][ny] = dist[x][y] + 1;
            q.push({nx, ny});
        }
    }
    return dist;
}
```

单源只是 `sources` 中只有一个起点的情形。带障碍网格还要在扩展时跳过障碍；若状态除位置外还受朝向等信息影响，判重也必须覆盖完整状态，见[状态与转移](../techniques/03_状态与转移.md)。

## 复杂度与状态边界

邻接表图的 BFS 时间为 O(V+E)，距离数组与队列占 O(V) 额外空间。四方向网格每点只检查四个邻居，因此搜索时间、距离数组与队列空间均为 O(nm)。若还需读入 `a` 个源点、回答 `b` 次查询，总时间为 O(nm+a+b)。上面的函数额外空间为 O(nm)，不计调用方已持有的源点表；原 P1332 程序还保存查询，空间为 O(nm+b)。

整数状态没有天然的棋盘边界，需要先证明可以截断到一个有限范围，再决定数组长度。应区分：

- 题目允许的状态，例如所有正整数。
- 搜索实际保留的状态，例如证明足够的 `[1,L]`。
- 存储可访问的下标，例如长度为 `L+1` 的数组允许下标 `0..L`。

“数组开大一点”只能暂时掩盖问题，不能解释搜索为何不漏最优解。具体上界证明和下标检查见[BFS 题解中的 CF520B](../../../problems/bfs.md#cf520b-整数状态与搜索上界)。
