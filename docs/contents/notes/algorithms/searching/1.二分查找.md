# 二分查找

二分查找（Binary Search）是一种基于分治思想的高效搜索算法，适用于有序的数据集合。每轮缩小一半搜索范围，直至找到目标元素或确定其不存在。

## 算法步骤

1. 用闭区间 `[left, right]` 表示尚未排除的元素，初始为 `[0, len - 1]`。
2. 计算中点 `mid = left + (right - left) / 2`。
3. 如果 `array[mid]` 等于目标，返回 `mid`；如果它小于目标，保留 `[mid + 1, right]`；否则保留 `[left, mid - 1]`。
4. 当 `left > right` 时，区间为空，返回 `-1`。

## 代码实现

```c
int binarySearch(const int *array, int len, int target) {
    int left = 0;
    int right = len - 1;

    // 闭区间非空时才读取 array[mid]；len == 0 时不会进入循环。
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (array[mid] == target) {
            return mid;
        } else if (array[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return -1;
}
```

### 为什么必须排除 `mid`

这一版使用闭区间，比较后已确认 `mid` 不是目标。因此更新指针时必须写 `left = mid + 1` 或 `right = mid - 1`，保证下一轮区间严格缩小。曾在 `array[mid] > target` 时写成 `right = mid`；当 `left == mid == right` 时区间不变，循环可能无法结束。

## 时间复杂度

二分查找的时间复杂度为O(log n)，因为每次比较后都将搜索范围缩小一半。

## 空间复杂度

二分查找的空间复杂度为O(1)，因为只使用了常数大小空间来存储指针和变量。

## 区间的闭合与开合

在二分查找中，区间的开闭影响了范围的定义：

- **闭区间 [left, right]**：表示搜索范围包括`left`和`right`位置的元素。
- **开区间 (left, right)**：表示搜索范围不包括`left`和`right`位置的元素。

本文代码使用闭区间。也可以使用半开区间 `[left, right)`，但循环条件和指针更新必须与所选区间约定一致。

## 优劣

**优点**：

- 高效：时间复杂度为O(log n)，适用于大规模有序数据。
- 简单：实现逻辑清晰，易于理解。
- 空间节省：空间复杂度为O(1)。

**缺点**：

- 适用范围有限：仅适用于有序数据集合。
- 需要能高效访问中间位置；链表不适合直接套用数组下标版。
- 小数据集时，线性查找可能更快。
