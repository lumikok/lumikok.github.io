# CSS 布局与响应式

先复用[盒模型](./6.盒模型.md)与[层叠、优先级与继承](./1.层叠、优先级与继承.md)，再选择布局方式。

## Grid：行列布局

```css
.content {
  display: grid;
  grid-template-columns: minmax(0, 1fr) minmax(0, 2fr);
  gap: 16px;
}
```

`grid-template-columns` 定义列；`fr` 按比例分配可用空间；`gap` 设置间隔；`minmax(0, ...)` 允许列收缩，避免内容的最小宽度把容器撑开。

## Flex：一维排列

```css
.actions {
  display: flex;
  flex-wrap: wrap;
  align-items: center;
  justify-content: space-between;
  gap: 8px;
}
```

`flex-direction` 控制主轴方向；`justify-content` 对齐主轴；`align-items` 对齐交叉轴；`flex-wrap: wrap` 允许换行。Grid 常用于整体行列，Flex 常用于按钮、工具栏等单方向排列。

## 响应式覆盖

```css
@media (max-width: 800px) {
  .content {
    grid-template-columns: minmax(0, 1fr);
  }
}
```

条件匹配时规则参与层叠；不是自动获得最高优先级。在来源、层级和选择器优先级相同等条件下，后写规则覆盖前写规则。断点数值应由布局需求决定。

## 表格溢出与按钮状态

```css
.table-wrapper { overflow-x: auto; }
button:disabled { opacity: 0.5; cursor: not-allowed; }
```

给表格外层容器横向滚动，避免宽表撑开整页。禁用按钮应设置 HTML `disabled` 属性或 JS `.disabled = true`，只改变颜色或鼠标样式不会禁止点击。

易错点：把页面具体宽度、颜色值当成固定规则；可复用的是布局属性、层叠条件和溢出处理。

参考：[MDN Grid 布局](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Grids)、[响应式设计](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/CSS_layout/Responsive_Design)。
