# 迭代器

迭代器（Iterator）提供访问和遍历序列的统一接口，是容器与算法之间的桥梁。

## 迭代器的本质

迭代器是一套行为要求：例如用 `*it` 访问当前位置、用 `++it` 前进、与终点比较。容器可以用类对象实现迭代器，普通数组指针也可以充当迭代器；它不等同于负责资源所有权的智能指针。算法依赖这些操作，无需知道容器如何存储元素。

```cpp
// 指针的行为
int arr[] = {1, 2, 3, 4, 5};
int *ptr = arr; // 指向数组的第一个元素
cout << *ptr << endl; // 输出1
ptr++; // 移动到下一个元素

// 迭代器的行为
vector<int> vec = {1, 2, 3, 4, 5};
vector<int>::iterator it = vec.begin(); // 指向容器的第一个元素
cout << *it << endl; // 输出1
it++; // 移动到下一个元素
```

## 迭代器的分类

根据不同的功能和操作能力，迭代器可以分为以下几类：

下列分类决定遍历与访问能力，**能否修改元素还要看迭代器及元素是否允许写入**。例如 `cbegin()` 得到的常量迭代器不能修改元素，`set` 的迭代器也不允许修改键。

### 输入迭代器（Input Iterator）

**保证可读和向前移动，不保证可写或多趟遍历。** 流输入迭代器是典型的单趟例子；不能假定它的副本能独立重走同一段输入。

```cpp
// 从输入流中读取数据的迭代器
istream_iterator<int> in_it(cin);
int value = *in_it; // 读取一个整数
++in_it; // 移动到下一个元素
```

### 输出迭代器（Output Iterator）

**保证写入和向前推进，不保证可读或多趟遍历。** 写输出流不等于遍历一个可反复读取的容器。

```cpp
// 向输出流写入数据的迭代器
ostream_iterator<int> out_it(cout, " ");
*out_it = 10; // 输出10
```

### 前向迭代器（Forward Iterator）

**可读，支持向前移动和多趟遍历；可写性另行判断。**

```cpp
// 典型容器： std::forward_list
forward_list<int> flist = {1,2,3};
auto it = flist.begin();
*it = 10; // 修改元素
int value = *it; // 读取元素
it++; //只能向前移动
```

### 双向迭代器（Bidirectional Iterator）

**在前向迭代器基础上支持 `--it`，可以多趟遍历。**

```cpp
// 典型容器： std::list, std::set, std::map
list<int> mylist = {1,2,3};
auto it = mylist.begin();
it++; // 向前移动
it--; // 向后移动
```

### 随机访问迭代器（Random Access Iterator）

**在双向迭代器基础上支持常数时间的偏移、距离计算及顺序比较。** 例如 `it + k`、`it2 - it1`；`list` 的迭代器不支持这些随机访问操作。

```cpp
// 典型容器： std::vector, std::deque, 原生数组
vector<int> vec = {1,2,3,4,5};
auto it = vec.begin();
it += 2; // 随机访问，移动到第三个元素
int value = *(it); // 读取第三个元素
if(it < vec.end()) { // 比较同一序列中的迭代器
    // ...
}
```

使用时先确认容器支持哪些操作，再选择算法；常用遍历与删除写法见[迭代器常用内容](./05_迭代器部分常用.md)。上述分类按常用传统接口介绍，C++20 还区分连续迭代器。参考：[C++ 标准草案：迭代器要求](https://eel.is/c++draft/iterator.requirements.general)。
