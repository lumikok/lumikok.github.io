# FastAPI 启动与学习导航

## 最小应用

```python
# main.py
from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def root():
    return {"message": "Hello"}
```

`FastAPI()` 创建应用；路径操作装饰器声明 HTTP 方法和路径；函数处理请求并返回数据。

```bash
pip install "fastapi[standard]"
fastapi dev main.py
# 或
uvicorn main:app --reload
```

- `main:app`：Python 模块 `main` 中的应用变量 `app`，不是 URL；
- `--reload`：开发时自动重载，生产部署不使用开发重载；
- 默认地址 `http://127.0.0.1:8000`，`Ctrl+C` 终止；
- `/docs`：交互文档；`/openapi.json`：接口 Schema。

启动时提示缺少依赖，应检查安装依赖的 Python 环境是否与实际运行环境一致。
