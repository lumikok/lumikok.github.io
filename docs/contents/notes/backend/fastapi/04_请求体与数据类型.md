# 请求体与数据类型

请求体是客户端发送的数据；响应体是服务器返回的数据。模型边界、PATCH 与输出过滤见[请求与响应模型](./01_请求与响应模型.md)。

## Pydantic 模型与字典

```python
from fastapi import FastAPI
from pydantic import BaseModel, Field

app = FastAPI()

class Item(BaseModel):
    name: str = Field(min_length=1)
    price: float = Field(gt=0)
    is_offer: bool | None = None

@app.post("/items")
def create_item(item: Item):
    data = item.model_dump()
    data["display_name"] = item.name
    return data
```

`item` 是经校验的模型对象；`item.name` 取属性；`model_dump()` 返回 Python 字典，`model_dump_json()` 返回 JSON 字符串。默认 `model_dump()` 可能仍含 UUID、datetime 等 Python 对象；`model_dump(mode="json")` 得到 JSON 兼容值。

## 单个、嵌入与多个请求体参数

```python
from typing import Annotated
from fastapi import Body

@app.put("/plain")
def plain(item: Item):
    return item

@app.put("/embedded")
def embedded(item: Annotated[Item, Body(embed=True)]):
    return item

@app.put("/multiple")
def multiple(item: Item, importance: Annotated[int, Body(gt=0)]):
    return {"item": item, "importance": importance}
```

| 接口 | JSON 结构 |
| --- | --- |
| `/plain` | `{"name":"书","price":10}` |
| `/embedded` | `{"item":{"name":"书","price":10}}` |
| `/multiple` | `{"item":{"name":"书","price":10},"importance":2}` |

单模型默认直接接收模型字段；`embed=True` 增加以参数名为键的一层。多个请求体参数各以参数名为键。标量要进入请求体时显式用 `Body()`。

## 嵌套模型与容器

```python
from pydantic import HttpUrl

class Image(BaseModel):
    url: HttpUrl

class Product(BaseModel):
    images: list[Image] = Field(default_factory=list)
    tags: set[str] = Field(default_factory=set)

@app.post("/products")
def products(product: Product):
    return product

@app.post("/images")
def images(data: list[Image]):
    return data
```

- `list[Image]` 校验列表内每个对象；`HttpUrl` 校验 URL；
- `set[str]` 从 JSON 数组解析并去重，输出为数组，顺序不保证；
- 单个 `data: list[Image]` 让请求体最外层为数组；
- `default_factory` 每次创建新的容器，清楚表达默认值生成方式。

## 转换模式与严格模式

```python
from pydantic import ConfigDict

class StrictItem(BaseModel):
    model_config = ConfigDict(strict=True)
    price: float
```

默认模式允许部分兼容值转换，例如数字字符串；严格模式限制转换。不同类型、Python 输入和 JSON 输入的规则可能不同，不能用“所有类型绝不转换”概括。是否开启严格模式应由接口契约决定，而不是所有正式接口一律开启。

## 常见类型的 JSON 表示

| Python 类型 | 常见 JSON 表示与注意点 |
| --- | --- |
| `UUID` | UUID 字符串 |
| `datetime` | ISO 时间字符串；是否含时区由值及约束决定 |
| `date`、`time` | 日期字符串、时刻字符串 |
| `timedelta` | 持续时间；Pydantic v2 默认 JSON 输出通常是 ISO 8601 持续时间字符串 |
| `set`、`frozenset` | 数组，元素唯一 |
| `bytes` | 按配置编码的字符串，默认需要有效 UTF-8 |
| `Decimal` | Pydantic v2 模型 JSON 输出通常为字符串，不能一律当 float |

自定义配置、直接返回响应对象和普通对象编码会影响序列化路径。对接时应检查实际响应和 Schema；`datetime` 类型本身不保证带时区。

## 文档示例

```python
class ExampleItem(BaseModel):
    model_config = ConfigDict(
        json_schema_extra={"examples": [{"name": "书", "price": 10}]}
    )
    name: str = Field(examples=["书"])
    price: float = Field(gt=0, examples=[10])
```

模型 `json_schema_extra` 提供整体 Schema 示例，`Field(examples=[...])` 提供字段示例。它们说明如何调用，不会给字段设置默认值，也不替代校验。

`Body(openapi_examples={...})` 可提供具名示例及摘要；`Body`、`Query`、`Path`、`Header`、`Cookie` 等也能声明示例或文档元数据。区分 Schema 的 `examples` 与 OpenAPI 的具名示例，不直接照抄含 `...` 的不完整字典。

参考：[多个请求体参数](https://fastapi.tiangolo.com/tutorial/body-multiple-params/)、[请求示例数据](https://fastapi.tiangolo.com/tutorial/schema-extra-example/)、[Pydantic 序列化](https://docs.pydantic.dev/latest/concepts/serialization/)。
