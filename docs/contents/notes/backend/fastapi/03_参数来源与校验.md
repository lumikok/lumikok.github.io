# 参数来源与校验

## 参数从哪里来

| 声明 | 来源 |
| --- | --- |
| 名称出现在路径 `{item_id}` 中 | 路径参数 |
| 非路径中的普通标量，如 `q: str` | 通常是查询参数 |
| 普通 Pydantic 模型参数 | 通常是 JSON 请求体 |
| `Query()`、`Body()`、`Header()`、`Cookie()` | 显式指定来源 |

不能概括成“所有非路径参数都是查询参数”。容器、模型、依赖等需要按声明判断。

## 路径、查询与必填

```python
from typing import Annotated
from fastapi import FastAPI, Path, Query

app = FastAPI()

@app.get("/items/{item_id}")
def read_item(
    item_id: Annotated[int, Path(gt=0)],
    q: Annotated[str | None, Query(min_length=1, max_length=50)] = None,
    limit: Annotated[int, Query(ge=1, le=100)] = 10,
):
    return {"id": item_id, "q": q, "limit": limit}
```

请求示例：`/items/3?q=book&limit=5`。`?` 后是查询参数，多个键值对由 `&` 分隔。

- 路径参数必须提供；类型不合法或违反约束时通常返回 `422`；
- 参数有默认值时可以省略；默认值与是否允许 `None` 是两回事；
- `q: str | None` 没有默认值，仍要求提供；`q: str | None = None` 才允许省略；
- 缺失、空字符串 `?q=` 与 JSON `null` 不同；查询中的 `q=null` 通常是字符串 `"null"`；
- `bool` 查询参数可解析 `true`、`1`、`on`、`yes` 等形式。

`Annotated[类型, 元数据]` 保留类型并附加参数校验。默认值放在 `= ...` 处。Python 普通位置参数不能把必填参数放在默认参数后；必要时使用 `*` 声明关键字专用参数。

## 校验与文档元数据

| 参数 | 用途 |
| --- | --- |
| `gt`、`ge`、`lt`、`le` | 大于、大于等于、小于、小于等于 |
| `min_length`、`max_length`、`pattern` | 长度与正则约束 |
| `alias` | 请求使用的外部名称 |
| `title`、`description` | 文档说明 |
| `deprecated=True` | 在文档标记弃用 |
| `include_in_schema=False` | 从 Schema 隐藏，不禁止调用 |

`Query`、`Path` 等从 FastAPI 导入，模型内 `Field` 从 Pydantic 导入。

## 重复查询参数与查询模型

```python
@app.get("/tags")
def read_tags(tags: Annotated[list[str] | None, Query()] = None):
    return {"tags": tags}
```

`/tags?tags=a&tags=b` 得到 `['a', 'b']`。列表查询参数显式使用 `Query()`，避免被解释为请求体。

```python
from pydantic import BaseModel, ConfigDict, Field

class Filters(BaseModel):
    model_config = ConfigDict(extra="forbid")
    limit: int = Field(default=10, ge=1, le=100)
    offset: int = Field(default=0, ge=0)
    tags: list[str] = Field(default_factory=list)

@app.get("/filtered")
def filtered(filters: Annotated[Filters, Query()]):
    return filters
```

字段分别从查询参数提取，不是从一个 JSON 字符串读取。查询参数模型需要 FastAPI `0.115.0` 或更新版本。[官方说明](https://fastapi.tiangolo.com/tutorial/query-param-models/)

## 自定义后置校验

```python
from pydantic import AfterValidator

def check_code(value: str) -> str:
    if not value.startswith(("a-", "b-")):
        raise ValueError("必须以 a- 或 b- 开头")
    return value

@app.get("/codes")
def read_code(code: Annotated[str, Query(), AfterValidator(check_code)]):
    return {"code": code}
```

`AfterValidator` 在内部类型校验之后运行；返回校验后的值，失败抛 `ValueError`。这只是后置校验器的行为，不能概括为所有自定义校验都最后执行。

## 枚举与包含斜杠的路径

```python
from enum import Enum

class ModelName(str, Enum):
    small = "small-model"
    large = "large-model"

@app.get("/models/{model}")
def read_model(model: ModelName):
    return {"name": model.name, "value": model.value}

@app.get("/files/{file_path:path}")
def read_path(file_path: str):
    return {"path": file_path}
```

枚举 `.name` 是成员名（`small`），`.value` 是实际值（`small-model`）；不要因为示例中两者相同就混用。路径字符串经校验后成为枚举成员，输出时序列化为其值。

`:path` 可匹配包含 `/` 的剩余路径；OpenAPI 无法完整表达这类路径语义。该示例只回显路径，真实读取文件还需验证允许的目录和访问边界。

固定路径 `/users/me` 应注册在 `/users/{user_id}` 前，避免 `me` 被动态路由先匹配。这是路由匹配顺序，不是函数参数声明顺序。

## Cookie 与 Header

```python
from fastapi import Cookie, Header

@app.get("/metadata")
def metadata(
    ads_id: Annotated[str | None, Cookie()] = None,
    user_agent: Annotated[str | None, Header()] = None,
    x_name: Annotated[list[str] | None, Header()] = None,
):
    return {"ads_id": ads_id, "user_agent": user_agent, "x_name": x_name}
```

- `Cookie()` 读取 Cookie；声明 Cookie 参数不会自动设置 Cookie；
- 请求头不区分大小写；`Header()` 默认将变量名中的 `_` 换成 `-`，例如 `user_agent` 对应 `User-Agent`；
- `convert_underscores=False` 可关闭替换，但部分代理不接受含 `_` 的请求头；
- `list[str]` 接收重复请求头的多个值，不是重复请求体。

```python
class CookieData(BaseModel):
    session_id: str

class HeaderData(BaseModel):
    user_agent: str | None = None

@app.get("/groups")
def groups(
    cookies: Annotated[CookieData, Cookie()],
    headers: Annotated[HeaderData, Header()],
):
    return {"cookies": cookies, "headers": headers}
```

Cookie/Header 模型同样需要支持参数模型的 FastAPI 版本。`extra="forbid"` 会拒绝模型外的数据；用于 Header 时要考虑客户端自动发送的标准头，不能机械照搬查询模型配置。

参考：[Header 参数](https://fastapi.tiangolo.com/tutorial/header-params/)、[Cookie 模型](https://fastapi.tiangolo.com/tutorial/cookie-param-models/)、[Header 模型](https://fastapi.tiangolo.com/tutorial/header-param-models/)。
