# 异步与数据库接入

## `def` 与 `async def`

| 路由/依赖的实现 | 选择 |
| --- | --- |
| 调用可等待的异步 I/O API | `async def`，按 API 使用 `await` |
| 调用阻塞式 I/O 库 | 普通 `def` 可由 FastAPI 在线程池执行 |
| 没有 I/O 的简单计算 | 按需求选择，不必机械加异步 |

FastAPI 调用的普通路由和依赖适用线程池机制；自己直接调用的普通工具函数不会自动被送到线程池。

```python
import asyncio

async def wait_async():
    await asyncio.sleep(1)
```

异步等待让出事件循环；在 `async def` 内直接使用 `time.sleep()` 或阻塞式网络调用，会阻塞当前事件循环。异步不自动提高 CPU 密集计算速度，线程池也不等于无限并发。

语言机制见[类方法与资源管理](../../languages/python/09_类方法与资源管理.md)。

## ORM 与表模型

ORM 将对象与数据库表关联，SQLModel 结合 Pydantic 数据模型和 SQLAlchemy 数据库能力。

```python
from sqlmodel import SQLModel, Field

class Item(SQLModel, table=True):
    id: int | None = Field(default=None, primary_key=True)
    name: str
```

`table=True` 声明表模型；`primary_key=True` 声明主键；无 `table=True` 的数据模型可以用于请求或响应。数据库持久化数据不随请求会话关闭而消失；进程内列表则不是持久化存储。

模型负责描述字段，不自动提供完整业务约束或权限检查。已有表结构变化时，`create_all()` 不会自动执行字段迁移。

## 通过依赖接入会话

```python
from typing import Annotated
from fastapi import Depends
from sqlmodel.ext.asyncio.session import AsyncSession

async def get_session():
    async with AsyncSession(engine, expire_on_commit=False) as session:
        yield session

SessionDep = Annotated[AsyncSession, Depends(get_session)]
```

示例的 `engine` 由数据库模块创建；每次请求取得会话，路由通过参数请求该资源。建表/引擎退出应按应用生命周期安排。
