# 欠拟合、过拟合与线性回归

## 欠拟合、过拟合与泛化

**泛化**是模型对未参与训练的新数据进行预测的能力。训练损失衡量对已有训练数据的拟合程度，不能单独证明泛化良好。

| 情况 | 含义 | 常见表现 |
| --- | --- | --- |
| 欠拟合 | 模型没有充分学到数据中的规律 | 训练和验证表现都较差 |
| 过拟合 | 模型过度贴合训练数据的噪声或偶然细节 | 训练表现很好，验证表现明显较差 |

### 表达能力与训练程度

对数据 `[(0, 1), (1, 3), (2, 5), (3, 7)]`：

- 常数模型 `ŷ = b` 无法同时输出不同的标签，表达能力受限。
- 线性模型 `ŷ = wx + b` 可以用 `w = 2, b = 1` 完全匹配这些数据。
- 线性模型尚未训练好时也可能误差较大，不能仅据当前训练损失就判断其表达能力不足。

更复杂的模型可以表达更多规律，也可能贴合噪声；**复杂模型不一定更差**。比较模型应结合验证数据，而不是只看训练成绩。

### 过拟合对照

人为设定基础规律为 `y = 2x`，训练集第二条标签额外增加 `1`：

- 训练数据：`[(1, 2), (2, 5), (3, 6)]`。
- 新数据：`[(1.5, 3), (2.5, 5), (4, 8)]`。
- 模型 A：`ŷ = 2x`。
- 模型 B：`ŷ = 2x + 1 - (x - 2)²`。

| 模型 | 训练 MAE | 新数据 MAE |
| --- | ---: | ---: |
| A | `1/3` | `0` |
| B | `0` | `1.5` |

B 完全贴合训练数据，却把人为加入的偏差带入预测。例如 `x = 4` 时，A 预测 `8`，B 预测 `5`。

训练和新数据的误差差距也可能来自数据分布变化或样本过少，不能把所有差距都直接归为过拟合。新输入处于训练输入的范围内，也不保证数据分布相同。

## 单变量线性回归

模型：`ŷ = wx + b`。

- `x`：输入特征。
- `w`：斜率，控制输入变化时预测值如何变化。
- `b`：截距，决定 `x = 0` 时的预测值。

训练的目标是根据训练数据寻找使损失较小的 `w` 和 `b`；预测时使用训练得到的参数。

### 平方误差损失

设训练集有 `m` 个样本，第 `i` 个样本的误差为 `e_i = wx_i + b - y_i`：

```text
J(w, b) = (1 / (2m)) × Σ e_i²
```

`Σ` 表示对全部训练样本求和。平方使正负误差不会抵消，并使较大的误差受到更大惩罚。除以 `m` 得到平均量；额外的 `1/2` 便于求导，不改变使损失最小的参数。

平方误差损失用于训练，MAE 可以用于评价；比较时要区分它们的定义，不能直接比较数值大小。MAE 与标签单位相同，平方误差的单位是标签单位的平方。

## 梯度下降

偏导数描述固定其他参数时，某个参数的微小变化对损失的影响。梯度由各参数的偏导数组成，用于确定参数更新方向。

```text
dw = ∂J/∂w = (1 / m) × Σ (e_i × x_i)
db = ∂J/∂b = (1 / m) × Σ e_i

w_new = w_old - α × dw
b_new = b_old - α × db
```

`α` 是学习率，控制每次更新的步长。负梯度给出当前位置的局部下降方向，步长过大可能会让更新后的损失更高。

但是越过最低点不一定会失败，参数可以在低点两侧来回移动。若逐渐靠近低点，仍可能收敛；若越跳越远、损失不断增大，则出现发散。

**两个梯度必须用同一组旧参数计算，再更新参数。** 如果更新 `w` 后才计算 `db`，就混用了不同位置的梯度。

### 一步更新

训练数据 `[(0, 1), (1, 3), (2, 5), (3, 7)]`，初始 `w = 1, b = 1`：

1. 预测值为 `[1, 2, 3, 4]`，误差为 `[0, -1, -2, -3]`。
2. 损失 `J = (0 + 1 + 4 + 9) / 8 = 1.75`。
3. 梯度 `dw = -14 / 4 = -3.5`，`db = -6 / 4 = -1.5`。
4. 学习率 `α = 0.1`，更新后 `w = 1.35, b = 1.15`，损失约为 `0.604375`。

### 最小实现

```python
def predict(x, w, b):
    return w * x + b


def cost(data, w, b):
    return sum((predict(x, w, b) - y) ** 2 for x, y in data) / (2 * len(data))


def gradients(data, w, b):
    dw, db = 0, 0
    for x, y in data:
        error = predict(x, w, b) - y
        dw += error * x
        db += error
    return dw / len(data), db / len(data)


def train(data, w, b, learning_rate, steps):
    for _ in range(steps):
        dw, db = gradients(data, w, b)
        w -= learning_rate * dw
        b -= learning_rate * db
    return w, b


train_data = [(0, 1), (1, 3), (2, 5), (3, 7)]
validation_data = [(0.5, 2), (2.5, 6)]
w, b = train(train_data, 1, 1, learning_rate=0.1, steps=1000)
validation_mae = sum(abs(predict(x, w, b) - y) for x, y in validation_data) / len(validation_data)
print(w, b, cost(train_data, w, b), validation_mae)
```

训练后参数约为 `(2, 1)`，训练损失与验证 MAE 都接近 `0`。

换成训练数据 `[(-1, 4), (0, 1), (1, -2), (2, -5)]`、验证数据 `[(-0.5, 2.5), (1.5, -3.5)]`，从 `(0, 0)` 开始使用相同步长和步数，参数约为 `(-3, 1)`。输入增大、标签减小时，斜率可以为负。

两组数据都是人为构造的无噪声线性数据，接近零误差不能证明真实任务也会无误差。验证数据只用于评价，不参与梯度计算；最终测试的分工见[训练、评估与数据泄漏](./01_%E8%AE%AD%E7%BB%83%E3%80%81%E8%AF%84%E4%BC%B0%E4%B8%8E%E6%95%B0%E6%8D%AE%E6%B3%84%E6%BC%8F.md)。

### 学习率对照

控制训练数据、初始参数和更新次数不变，只改变学习率，才能比较步长对训练结果的影响。沿用上面的训练数据，每组都从 `(w, b) = (1, 1)` 开始，更新 20 步。

| 学习率 | 第 0 步损失 | 第 1 步损失 | 第 20 步损失 |
| ---: | ---: | ---: | ---: |
| `0.01` | `1.75` | `1.608044` | `0.333138` |
| `0.1` | `1.75` | `0.604375` | `0.007996` |
| `0.5` | `1.75` | `2.109375` | `81.710196` |
| `1.0` | `1.75` | `17.687500` | `2.859242 × 10²⁰` |

- `0.01` 与 `0.1` 的损失都下降，`0.1` 在相同步数下下降更多。
- `0.5` 与 `1.0` 都发散。把步长从 `1.0` 减到 `0.5` 只是让发散变慢，并没有使训练稳定；**比过大步长更小，不代表已经足够小**。
- 第 20 步仍有误差，不等于模型欠拟合。同一线性模型训练 1000 步已接近零误差，这里只是尚未充分收敛。

应观察连续多步的损失变化，而不是仅凭一次跨过低点就判断发散。稳定的步长取决于数据和损失函数，不能把本例的学习率当作所有任务的固定阈值。

复现时，每组先记录更新前的损失，再记录 20 次更新后的损失，共 21 个值；不要让下一组接着上一组的参数训练。

## 实现易错点

- **损失除以 `2m`，梯度除以 `m`**：平方求导产生的 `2` 抵消了损失前的 `1/2`。梯度再除以 `2m` 会少一倍。
- **接收训练返回值后再评价**：使用 `w, b = train(...)`。只打印返回值不会更新调用处的 `w`、`b`，随后计算的仍是旧参数损失。
- **对照不同训练步数时保持相同起点**：比较一步与 1000 步的结果，应分别从指定初始参数开始，避免意外接着上次结果训练。
- **预测公式与手算一致**：模型 B 的平方项前是减号；符号写错会导致代码结果与手算不同。
