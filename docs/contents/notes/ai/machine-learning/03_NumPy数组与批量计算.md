# NumPy 数组与批量计算

## 数组与形状

NumPy 数组适合批量数值计算。用 `np.array(...)` 创建数组，`dtype=float` 指定使用浮点数存储元素。

```python
import numpy as np

data = np.array([[0, 1],
                 [1, 3],
                 [2, 5],
                 [3, 7]], dtype=float)

x = data[:, 0]
y = data[:, 1]
```

这里每行是一条样本，两列分别是输入 `x` 和标签 `y`。

**`shape` 是描述各个轴长度的元组，不总是“行数、列数”。**

| 对象 | `shape` | 含义 |
| --- | --- | --- |
| `data` | `(4, 2)` | 二维数组，4 行 2 列 |
| `x`、`y` | `(4,)` | 一维数组，各有 4 个元素 |

`(4,)` 只有一个轴，不能当作二维的 `(4, 1)`。末尾逗号表示只有一个元素的元组；一维数组没有单独的行、列两条轴。

## 索引与取列

二维数组使用 `data[行, 列]`，索引从 `0` 开始。冒号 `:` 表示取该轴上的全部元素。

| 表达式 | 含义 | 结果 |
| --- | --- | --- |
| `data[2, 1]` | 第 3 行、第 2 列的元素 | `5.0` |
| `data[:, 0]` | 全部行的第 1 列 | `[0., 1., 2., 3.]`，形状 `(4,)` |
| `data[:, 1]` | 全部行的第 2 列 | `[1., 3., 5., 7.]`，形状 `(4,)` |
| `data[1, :]` | 第 2 行的全部列 | `[1., 3.]`，形状 `(2,)` |

用整数指定一列后，取出的列是一维数组。读取数组内容用 `print(x)`，查看形状用 `print(x.shape)`。

## 批量预测与损失

数组与标量的基本算术逐元素进行；两个同形数组相减时，对应位置相减。于是同一个线性模型可以一次计算所有样本：

```python
w, b = 1, 1
predictions = w * x + b
residuals = predictions - y
J = np.mean(residuals ** 2) / 2

print(predictions)        # [1. 2. 3. 4.]
print(residuals)          # [ 0. -1. -2. -3.]
print(J)                  # 1.75
print(predictions.shape)  # (4,)
```

`np.mean(...)` 在这里对全部元素求平均。因此 `np.mean(residuals ** 2) / 2` 等价于逐样本循环计算 `Σ(预测值 - 标签)² / (2m)`，与[线性回归的平方误差损失](./02_欠拟合、过拟合与线性回归.md)一致。

`x`、`y`、预测值和残差都保持 `(m,)`，每个位置对应同一条样本。检查形状可以帮助发现取错行列或混用不同维度的问题。

## 跳过编号列

数据有多列时，应根据列的含义选择输入与标签，不能固定认为前两列就是 `x`、`y`。下面三列依次为记录编号、输入、标签：

```python
data2 = np.array([[101, 0, 2],
                  [102, 1, 5],
                  [103, 2, 8]], dtype=float)

x2 = data2[:, 1]
y2 = data2[:, 2]
predictions2 = 2 * x2 + 1
residuals2 = predictions2 - y2
J2 = np.mean(residuals2 ** 2) / 2

print(predictions2)  # [1. 3. 5.]
print(residuals2)    # [-1. -2. -3.]
print(J2)            # 2.3333333333333335，即 7/3
```

编号列不参与预测。`x2`、`y2`、预测值和残差的形状均为 `(3,)`。

这里使用固定参数 `w = 2, b = 1`，并未训练参数来拟合这组数据；损失非零是正常结果，不代表取列或数组计算错误。
