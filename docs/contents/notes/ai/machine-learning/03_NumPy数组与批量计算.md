# NumPy 数组与批量计算

## 数组与形状

用 `np.array(...)` 创建数组，`dtype=float` 指定使用浮点数存储元素。

```python
import numpy as np

data = np.array([[0, 1],
                 [1, 3],
                 [2, 5],
                 [3, 7]], dtype=float)

x = data[:, 0]
y = data[:, 1]
```

这里每行是一条样本，两列分别是输入 `x` 和标签 `y`。

**`shape` 是描述各个轴长度的元组，不总是“行数、列数”。**

| 对象 | `shape` | 含义 |
| --- | --- | --- |
| `data` | `(4, 2)` | 二维数组，4 行 2 列 |
| `x`、`y` | `(4,)` | 一维数组，各有 4 个元素 |

`(4,)` 只有一个轴，不能当作二维的 `(4, 1)`。末尾逗号表示只有一个元素的元组；一维数组没有单独的行、列两条轴。

## 索引与取列

二维数组使用 `data[行, 列]`，索引从 `0` 开始。冒号 `:` 表示取该轴上的全部元素。

| 表达式 | 含义 | 结果 |
| --- | --- | --- |
| `data[2, 1]` | 第 3 行、第 2 列的元素 | `5.0` |
| `data[:, 0]` | 全部行的第 1 列 | `[0., 1., 2., 3.]`，形状 `(4,)` |
| `data[:, 1]` | 全部行的第 2 列 | `[1., 3., 5., 7.]`，形状 `(4,)` |
| `data[1, :]` | 第 2 行的全部列 | `[1., 3.]`，形状 `(2,)` |

用整数指定一列后，取出的列是一维数组。读取数组内容用 `print(x)`，查看形状用 `print(x.shape)`。

## 批量预测与损失

数组与标量的基本算术逐元素进行；两个同形数组相减时，对应位置相减。于是同一个线性模型可以一次计算所有样本：

```python
w, b = 1, 1
predictions = w * x + b
residuals = predictions - y
J = np.mean(residuals ** 2) / 2

print(predictions)        # [1. 2. 3. 4.]
print(residuals)          # [ 0. -1. -2. -3.]
print(J)                  # 1.75
print(predictions.shape)  # (4,)
```

`np.mean(...)` 在这里对全部元素求平均。因此 `np.mean(residuals ** 2) / 2` 等价于逐样本循环计算 `Σ(预测值 - 标签)² / (2m)`，与[线性回归的平方误差损失](./02_欠拟合、过拟合与线性回归.md)一致。

`x`、`y`、预测值和残差都保持 `(m,)`，每个位置对应同一条样本。检查形状可以帮助发现取错行列或混用不同维度的问题。

## 跳过编号列

数据有多列时，应根据列的含义选择输入与标签，不能固定认为前两列就是 `x`、`y`。下面三列依次为记录编号、输入、标签：

```python
data2 = np.array([[101, 0, 2],
                  [102, 1, 5],
                  [103, 2, 8]], dtype=float)

x2 = data2[:, 1]
y2 = data2[:, 2]
predictions2 = 2 * x2 + 1
print(predictions2)  # [1. 3. 5.]
```

编号列不参与预测。`x2`、`y2`、预测值和残差的形状均为 `(3,)`。

这里仍使用固定参数，取列之后的残差与损失按前文公式计算即可。

## 数组梯度与训练

向量化替换的是**逐样本计算**，训练中按步数反复更新参数的循环仍然保留。单变量实现中，`x`、`y` 与残差 `e = w * x + b - y` 都应为同形的一维数组 `(m,)`，`w`、`b` 为标量，且样本数 `m > 0`。

| 计算 | 逐样本公式 | 数组表达式 |
| --- | --- | --- |
| 损失 | `Σ e_i² / (2m)` | `np.sum(e ** 2) / (2 * m)` |
| `w` 的梯度 | `Σ(e_i × x_i) / m` | `np.dot(e, x) / m` |
| `b` 的梯度 | `Σ e_i / m` | `np.sum(e) / m` |

当 `e`、`x` 都是一维数组时，`np.dot(e, x)` 表示对应元素相乘后求和，结果是标量。它不只是逐元素乘法；`e * x` 的结果仍是一个数组。

下面将数组实验中的计算整理为三个函数，复用前文的 `x`、`y`：

```python
def cost_np(x, y, w, b):
    e = w * x + b - y
    return np.sum(e ** 2) / (2 * len(x))


def gradients_np(x, y, w, b):
    e = w * x + b - y
    return np.dot(e, x) / len(x), np.sum(e) / len(x)


def train_np(x, y, w, b, learning_rate, steps):
    for _ in range(steps):
        dw, db = gradients_np(x, y, w, b)
        w -= learning_rate * dw
        b -= learning_rate * db
    return w, b


w_fit, b_fit = train_np(x, y, 1.0, 1.0, learning_rate=0.1, steps=1000)
final_loss = cost_np(x, y, w_fit, b_fit)
```

每轮先用同组旧参数计算两个梯度，再更新 `w`、`b`；评价时使用接收的训练后参数。相关机制与返回值易错点见[欠拟合、过拟合与线性回归](./02_欠拟合、过拟合与线性回归.md)。

### 与循环版对照

**检查数组版结果是否有误**：保持数据、初始参数、学习率和步数相同，按“损失与梯度 → 一步更新 → 多步训练”的顺序比较，可以在最早出现差异的位置排查问题。

原数据 `[(0, 1), (1, 3), (2, 5), (3, 7)]`，从 `(w, b) = (1, 1)` 开始，学习率为 `0.1`：

| 检查项 | 循环版与数组版结果 |
| --- | --- |
| 初始损失 | `1.75` |
| 初始梯度 | `(-3.5, -1.5)` |
| 一步后参数 | `(1.35, 1.15)` |
| 1000 步后参数 | 约 `(2, 1)` |

梯度及一步、1000 步的参数在相对与绝对容差均为 `1e-10` 时一致。浮点计算可能产生微小差异，不应只用严格的 `==` 判断实现是否等价。

更换样本数时，输入、标签及残差仍应同形，损失和梯度按实际 `m` 求平均；完整换数据实验见文末源码。

**向量化为何通常更快**：逐元素循环交给 NumPy 优化后的已编译代码执行，减少 Python 逐项循环与对象操作的开销。底层还可能使用 SIMD 或多线程等优化，但向量化本身不等于“并行计算”，也不保证任何规模下都更快。

## 广播与交叉残差

不同形状的数组相减不一定报错。NumPy 会从末尾对齐各轴，长度相同或其中一个为 `1` 的轴可以兼容；缺失的轴按长度 `1` 处理。

因此，`(m,)` 与 `(m, 1)` 相减时，前者按 `(1, m)` 对齐，结果扩展成 `(m, m)`，产生样本间的交叉相减，而不是每个预测只减去自己的标签。

两条样本的形状示意：

```python
pred_small = np.array([1., 2.])       # (2,)
labels_col = np.array([[1.], [3.]])   # (2, 1)
cross_errors = pred_small - labels_col
print(cross_errors)
# [[ 0.  1.]
#  [-2. -1.]]
```

正确的一一对应残差应只有两个：`[0., -1.]`，而不是四个。错误形状下仍可能算出一个损失值，所以**能运行不代表含义正确**；因此，在单变量实现中应先确认 `x`、`y`、预测和残差都为 `(m,)`。

## 多特征加权求和

每个样本有多个特征时，预测是各特征与对应权重的加权和，再加偏置：`ŷ = w₁x₁ + w₂x₂ + … + b`。

```python
X = np.array([[2, 3],
              [1, 4],
              [0, 2]], dtype=float)
weights = np.array([4, -1], dtype=float)
bias = 5.0

pred_multi = X @ weights + bias
print(pred_multi)  # [10.  5.  3.]
```

| 对象 | 形状 | 含义 |
| --- | --- | --- |
| `X` | `(m, n)` | 每行一个样本，每列一个特征 |
| `weights` | `(n,)` | 每个特征对应一个权重 |
| `bias` | 标量 | 加到每条样本的加权和上 |
| 预测结果 | `(m,)` | 每条样本得到一个预测 |

这里 `(3, 2) @ (2,) → (3,)`。第一条样本的预测为 `2 × 4 + 3 × (-1) + 5 = 10`。`@` 对每行和权重求点积；`*` 只做逐元素乘法，不会自动把各特征的贡献求和。
