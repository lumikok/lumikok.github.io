# 训练、评估与数据泄漏

## 样本、特征与标签

| 概念 | 含义 | 快递估时例子 |
| --- | --- | --- |
| 样本 | 一条参与学习或评价的数据 | 一次配送记录 `(距离, 耗时)` |
| 特征 `x` | 预测时使用的输入 | 配送距离 |
| 标签 `y` | 训练或评价时使用的真实目标值 | 实际配送耗时 |
| 数据集 | 多个样本的集合 | 多次配送记录组成的列表 |

预测新样本时，输入特征，输出预测值 `ŷ`；真实标签不能作为预测输入。训练时同时使用特征和标签，才能计算误差。

预测连续数值属于**回归**，预测离散类别属于**分类**。快递耗时和人格连续分数都属于回归。

## 模型、参数与训练

模型给出从输入到预测值的计算规则，参数决定这个规则的具体取值。

本次固定模型为 `ŷ = 3x + b`：系数 `3` 固定，只训练参数 `b`。训练就是用训练数据比较候选参数，选择损失较小的参数；预测则使用选定的参数计算新输入的结果。

**绝对误差**：`|ŷ - y|`。

**本次训练损失**：全部训练样本的绝对误差之和。损失用于选择参数；评价指标用于衡量预测效果，两者可以使用相同的计算方式。

**平均绝对误差（MAE）**：`绝对误差之和 / 样本数`。单位与目标值相同，越小表示平均预测偏差越小。

### 最小实验

训练集：`[(1, 8), (2, 12), (3, 13)]`；测试集：`[(4, 19), (5, 22)]`。枚举整数 `b = 0～10`，只根据训练损失选参。

```python
train = [(1, 8), (2, 12), (3, 13)]
test = [(4, 19), (5, 22)]

def total_error(b, data):
    total = 0
    for x, y in data:
        total += abs(3 * x + b - y)
    return total

errors = [total_error(b, train) for b in range(11)]
best_b = errors.index(min(errors))
test_mae = total_error(best_b, test) / len(test)

print(best_b, min(errors), test_mae)  # 5 2 2.0
```

选定 `b = 5` 后，训练预测为 `[8, 11, 14]`，绝对误差为 `[0, 1, 1]`；测试预测为 `[17, 20]`，绝对误差为 `[2, 2]`，因此测试 MAE 为 `2.0`。

这里的枚举是在固定模型中训练参数 `b`，没有比较不同模型或特征方案，也没有使用验证集。

## 训练集、验证集与测试集

| 数据 | 职责 | 本次对应操作 |
| --- | --- | --- |
| 训练集 | 学习模型参数、确定预处理规则 | 选择 `b`，计算缩放所需的最大值 |
| 验证集 | 比较模型、特征方案或超参数，指导调整 | 本次小实验未使用 |
| 测试集 | 对最终选定的方案进行独立评价 | 计算最终测试 MAE |

流程：**训练 → 验证与调整 → 方案确定 → 最终测试**。

易错点：曾认为测试集评分后可以反复调整，再换测试集。调整应由验证结果指导；如果根据测试结果修改方案，原测试集已经参与决策，不能继续当作独立的最终评价。

## 数据泄漏

数据泄漏指训练或方案选择使用了本不应获得的信息，例如测试集统计量或真实标签，导致评价无法可靠反映对新数据的预测能力。

### 按预测对象切分

在人格预测任务中，一个用户及其帖子对应一个用户级样本；帖子是该样本的输入内容。1000 个用户对应 1000 个用户级样本，而不是把全部帖子看成一个样本。

若目标是预测新用户，应先按用户划分训练、验证和测试集。同一用户的帖子或拆分块应留在同一组；需要拆块时，在所属组内处理。

易错点：曾把按帖子拆分的风险归为“数据完整性”。关键问题是同一用户的信息跨组，模型可能利用已见用户的模式，评价不能代表对新用户的能力。

### 预处理规则只从训练集学习

先划分数据，再用训练集计算缩放、均值填补等规则，最后对验证和测试集应用同一规则。不能因为测试值超出训练范围就重新计算规则。[预处理与泄漏说明](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)

本次缩放对照：训练距离 `[1, 2, 3]`，测试距离 `[4, 10]`，每个值除以选定的最大值。

| 最大值来源 | 最大值 | 缩放后的测试值 | 是否适合独立评价 |
| --- | --- | --- | --- |
| 仅训练集 | `3` | `[4/3, 10/3]` | 是 |
| 训练集与测试集合并 | `10` | `[0.4, 1.0]` | 否，测试数据影响了规则 |

易错点：第一次选择了全数据最大值。用训练最大值缩放后，测试值大于 `1` 是合理结果；它表示测试值超出了训练集的最大值。

同理，均值填补应使用训练集中非缺失值的均值，不能把验证或测试数据加入均值计算。
