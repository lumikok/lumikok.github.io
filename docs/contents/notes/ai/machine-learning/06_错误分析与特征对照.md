# 错误分析与特征对照

错误分析把总指标还原为具体问题：哪些样本错了、属于什么错误、现有输入或模型可能遗漏了什么。它用来提出可检验的改进假设；观察到几条错误，并不等于已经找到了原因。

## 先建立可比较的基线

基线是一个简单、明确的参照方案，用来判断新模型的效果是否值得关注。例如二分类中的**多数类基线**始终预测训练集中数量最多的类别：

```text
majority = 训练集中的多数类别
baseline_error = 验证集中标签不等于 majority 的样本数 / 验证样本数
```

多数类必须由训练集决定，不能看过验证标签后再选。验证集的类别比例可能与训练集稍有不同，所以这条基线的验证错误率也可能超过 `50%`。

原 Iris 实验排除 setosa，只区分 versicolor 与 virginica，并比较四项测量特征与花瓣两项特征。一次划分中，多数类基线错误率为 `52%`，四特征逻辑回归为 `8%`。它说明模型在这次验证上优于简单策略，不代表已证明其他划分或真实任务中的效果。

训练、验证样本先固定；均值和标准差只从训练集计算，再用于验证集。基线、候选模型也必须在同一验证集上评价，分工见[训练、评估与数据泄漏](./01_训练、评估与数据泄漏.md)。

## 从错分样本提出假设

检查错误时，同时看原始输入、真实标签、预测概率与错误类型。原始测量值有助于理解样本，标准化后的数值主要服务于模型计算；不要把两者混淆。

下面保留实验中定位错误的代码片段，变量沿用已计算的验证结果：

```python
error_indices = np.where(y_val != y_val_pred)[0]
error_records = X_val_raw[error_indices]
error_labels = y_val[error_indices]
error_probabilities = y_val_p[error_indices]
```

这里的索引属于当前验证数组，不是原始数据集行号。概率在阈值附近的错分和高置信度错分都值得检查，但仅凭概率或少量个例不能断定原因。

Iris 实验从错分记录出发，检验“萼片特征是否在花瓣特征之外提供额外分类信息”：删去萼片两列，重新训练模型，再比较表现。**信息减少可能使错误率上升只是一个假设，结果也可能持平或改善。** 不要把“增加特征”直接等同于“模型一定更好”。

## 公平地做特征消融

特征消融通过移除部分输入、重新训练和评价，检查这些输入在当前模型与设置中的作用。只在预测时删列，既不匹配权重形状，也不能代替重新训练后的对照。

| 要控制的因素 | 理由 |
| --- | --- |
| 相同训练、验证样本及标签 | 避免把样本难度差异归因于特征变化 |
| 可比较的初始化与训练预算 | 避免把起点或优化程度的差异归因于特征变化 |
| 相同的预处理原则 | 每组都只用当前训练集拟合统计量，避免泄漏 |
| 固定阈值、统一评价指标 | 避免特征变化和决策规则变化混在一起 |

维度不同的模型不要求参数数组完全相同；原实验用零权重、零偏置，使两组初始概率同为 `0.5`，并保持学习率、步数一致。标准化独立作用于每列，因此从标准化数组取花瓣两列，等价于先选原始两列再使用对应的训练统计量。

一次划分的代表结果如下，完整条件和输出见文末实验源码：

| 模型 | 验证交叉熵 | 验证错误率 |
| --- | ---: | ---: |
| 四特征 | 约 `0.165` | `8%` |
| 仅花瓣两特征 | 约 `0.231` | `12%` |

花瓣模型训练错误更少，验证错误却更多，说明训练集错得更少不保证验证表现更好。两组还保留了两条共同的错分：总体指标改善与解决某一类具体错误是不同的判断。

交叉熵评价概率，错误率统计阈值后的对错，FP/FN 区分错误类型。它们不能互相替代；含义见[阈值与错误代价](./05_逻辑回归.md#阈值与错误代价)。

## 更换划分后限定结论

小验证集的结果容易受少量样本影响。例如验证集有 `25` 条样本，一条错分就改变 `4` 个百分点。比较其他划分时，每次都应重新划分、重新拟合训练统计量、重新初始化两组模型，不能沿用上一组模型或统计量。

原实验在预先确定的四个划分上，四特征模型的验证交叉熵都更低，但错误率有时持平、有时更低；一次持平的对照中，两组分别出现 FP 与 FN。由此保留两个判断：**概率质量改善不一定改变错误率，错误率相同也可能有不同错误代价。**

结论只限于所用模型、训练设置和观察到的划分，原因包括：

- 多个划分的验证样本可能重叠，不能当作多份互不相关的独立测试集。
- 随机种子用于复现划分，不应挑出最好看的种子作为最终成绩。
- 验证结果用于选择特征或调整方案后，不能再把它当作最终独立测试结果。

因此，消融支持的是“这些特征在当前比较中有额外价值”，不是“任何划分、任何模型都必须保留这些特征”。
