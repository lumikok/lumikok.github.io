# 错误分析与特征对照

错误分析是对分类结果进行人工审查：哪些样本错了、错了多少、可能为什么错，再据此考虑新特征或算法调整。它帮助提出改进假设，具体改动是否有效仍需通过对照实验检验。

## 先建立可比较的基线

Iris 二分类例子排除 setosa，只区分 versicolor 与 virginica，分别映射为 `0`、`1`。共 100 条样本，四列依次为萼片长度、萼片宽度、花瓣长度、花瓣宽度，单位为 cm。

使用 `train_test_split(X, y, test_size=0.25, stratify=y, random_state=42)` 得到 75 条训练样本、25 条验证样本。`stratify` 尽量保持类别比例，固定随机种子便于复现同一次划分。

均值和标准差只从训练集计算，再对训练、验证应用同一变换；模型只用训练集更新参数。相关机制见[特征缩放与标准化](./04_多特征线性回归.md#特征缩放与标准化)，训练公式见[逻辑回归](./05_逻辑回归.md)。

**多数类基线**始终预测训练集中数量最多的类别，用来判断模型是否优于简单策略；多数类不能由验证集决定。

种子 `42` 下，训练标签 `0/1` 的数量为 `37/38`，所以基线始终预测 `1`。验证集中有 13 条标签为 `0`，基线错误率为 `13/25 = 52%`，而四特征模型的验证错误率为 `8%`。这说明该模型在本次划分上优于此基线，不代表已经证明其在其他数据上同样有效。

## 从错分样本提出假设

只看错误总数，无法知道模型具体错在哪里。保留验证集的原始测量值，并定位错分样本：

```python
# 沿用实验中的真实标签、预测标签、概率和原始测量数组
error_indices = np.where(y_val != y_val_pred)[0]
error_records = X_val_raw[error_indices]
error_labels = y_val[error_indices]
error_probabilities = y_val_p[error_indices]
```

四特征模型的两条错误记录如下，索引是当前验证数组中的位置，不是原始数据集行号：

| 索引 | 四项原始测量值 | 真实标签 | 预测为 `1` 的概率 | 错误类型 |
| --- | --- | ---: | ---: | --- |
| `2` | `4.9, 2.5, 4.5, 1.7` | `1` | 约 `0.4677` | FN |
| `22` | `5.9, 3.2, 4.8, 1.8` | `0` | 约 `0.5729` | FP |

这些记录提供了检查方向，但仅凭两条错分还不能判断某类特征是否有帮助。本例进一步检验：**萼片特征是否在花瓣特征之外提供了额外分类信息。**

具体改动是删去前两列，只保留花瓣长度和宽度。预期是可用信息减少可能提高错误率，同时观察交叉熵；这只是待检验的假设，实际结果也可能持平或改善。

## 公平地做特征消融

特征消融通过移除部分输入、重新训练和评价，检查这些输入在当前模型及实验设置中的作用。本例对照四特征模型与花瓣两特征模型：

| 控制项 | 做法 |
| --- | --- |
| 样本与标签 | 同一种子下共用相同的训练、验证样本 |
| 初始化 | 两组均从零权重、零偏置开始，初始概率均为 `0.5` |
| 预处理 | 每列只用当前训练集统计量标准化 |
| 训练设置 | 学习率 `0.1`，训练 `1000` 步 |
| 分类与评价 | 阈值固定为 `0.5`，比较交叉熵、错误率、FP/FN |

此处标准化独立作用于各列，因此从标准化数组取 `[:, 2:4]`，与先选原始花瓣两列再用对应训练统计量标准化等价。不能改动特征的同时更换划分或训练设置，再把结果全部归因于删列。

种子 `42` 的结果：

| 指标 | 四特征 | 仅花瓣两特征 |
| --- | ---: | ---: |
| 训练集错误率 | `4%` | `2.67%` |
| 验证集交叉熵 | `0.1652` | `0.2309` |
| 验证集错误率 | `8%` | `12%` |
| 验证集 FP / FN | `1 / 1` | `1 / 2` |

原两条错误在花瓣模型中仍存在，且多出一条 FN。该划分下，加入萼片特征改善了验证指标，但没有纠正原来的两条错误。

花瓣模型的训练错误率更低，验证错误率却更高，说明**训练集错得更少不保证验证表现更好**。交叉熵评价概率，错误率只统计阈值后的对错，FP/FN 进一步区分错误类型；这些指标不能互相替代，定义见[阈值与错误代价](./05_逻辑回归.md#阈值与错误代价)。

## 更换划分后限定结论

验证集只有 25 条，一条错分就改变 4 个百分点，不能只依赖一次划分。使用预先确定的种子 `0、1、2、42`，每次都从原始数据重新划分、重新计算训练统计量，并让两组模型重新从零训练。

下表按“四特征 / 花瓣两特征”排列：

| 随机种子 | 验证集交叉熵 | 验证集错误率 |
| ---: | --- | --- |
| `0` | `0.0393 / 0.0488` | `0% / 0%` |
| `1` | `0.0567 / 0.0737` | `0% / 0%` |
| `2` | `0.0827 / 0.0928` | `4% / 4%` |
| `42` | `0.1652 / 0.2309` | `8% / 12%` |

四特征模型在这四次划分中验证交叉熵均更低；错误率在前三次持平，仅种子 `42` 下更低。种子 `2` 下，两组虽然都只错一条，四特征模型是 FP，花瓣模型却是 FN：**错误率相同也可能对应不同的错误代价。**

这些结果支持萼片特征在本次模型与训练设置中的额外价值，不能推广为所有划分下都稳定有益：

- 四次验证集可能重叠，不是四份互不相关的独立测试集。
- 不应挑表现最好的种子作为最终成绩，应保留全部对照结果。
- 这些是用于比较方案的验证结果，没有独立最终测试集，不能当作独立测试成绩。
