# 多特征线性回归

## 模型与形状

每条样本有 `n` 个特征时，预测为 `ŷ = w₁x₁ + … + wₙxₙ + b`，批量表示为 `predictions = X @ w + b`。

| 对象 | 形状 | 含义 |
| --- | --- | --- |
| `X` | `(m, n)` | `m` 条样本，每行包含 `n` 个特征 |
| `w` | `(n,)` | 每个特征对应一个权重 |
| `b` | 标量 | 所有样本共用的偏置 |
| `y`、预测与残差 `e` | `(m,)` | 每条样本对应一个标签、预测和残差 |

数组取列、一维形状和广播易错点见[NumPy 数组与批量计算](./03_NumPy数组与批量计算.md)。下面使用四条两特征样本：

```python
import numpy as np

X = np.array([[0, 0],
              [1, 0],
              [0, 1],
              [1, 1]], dtype=float)
y = np.array([1, 3, 0, 2], dtype=float)
```

## 梯度为何按特征列聚合

设 `e_i = ŷ_i - y_i`，损失仍为平方误差之和除以 `2m`：

```text
J = Σ e_i² / (2m)
dw_j = Σ (e_i × X_ij) / m
db = Σ e_i / m
```

`dw_j` 是第 `j` 个权重的梯度：将每条样本的残差乘以它的第 `j` 个特征，再对全部样本取平均。**每个权重对应一列特征，求和对象是样本，而不是特征。** 偏置对每条预测的影响系数都为 `1`，因此其梯度是残差均值。

转置 `X.T` 将原来的每列特征变成一行，便于一次计算全部权重梯度：

```text
dw = X.T @ e / m
db = np.sum(e) / m

X.T: (n, m)
e:   (m,)
dw:  (n,)
```

`X.T @ e` 的每个分量正好是对应特征列与残差的点积；除以 `m` 后得到平均梯度，结果与 `w` 的形状一致。

### 初始梯度例子

对上面的数据，从 `w = [0, 0]、b = 0` 开始，预测全为 `0`，残差为 `[-1, -3, 0, -2]`：

- 第一列是 `[0, 1, 0, 1]`，`dw₁ = (-3 - 2) / 4 = -1.25`。
- 第二列是 `[0, 0, 1, 1]`，`dw₂ = (0 - 2) / 4 = -0.5`。
- `db = (-1 - 3 + 0 - 2) / 4 = -1.5`，初始损失为 `1.75`。

学习率为 `0.1` 时，一步更新得到 `w = [0.125, 0.05]、b = 0.15`。

## 最小训练实现

以下按实验源码精简整理，输入满足前述形状且 `m > 0`：

```python
def cost_multi(X, y, w, b):
    m = len(y)
    e = X @ w + b - y
    return np.sum(e ** 2) / (2 * m)


def gradients_multi(X, y, w, b):
    m = len(y)
    e = X @ w + b - y
    return X.T @ e / m, np.sum(e) / m


def train_multi(X, y, w, b, learning_rate, steps):
    for _ in range(steps):
        dw, db = gradients_multi(X, y, w, b)
        w -= learning_rate * dw
        b -= learning_rate * db
    return w, b


w_fit, b_fit = train_multi(X, y, np.zeros(2), 0.0, 0.1, 1000)
final_loss = cost_multi(X, y, w_fit, b_fit)
```

关键约束：

- **样本数从函数输入确定**：使用函数内的 `len(y)`，不能依赖某组旧数据的全局 `m`。更换样本数后，损失和梯度都必须按新样本数取平均。
- **同组旧参数计算全部梯度，再统一更新**，并接收训练返回值后评价。相关原因见[梯度下降与实现易错点](./02_欠拟合、过拟合与线性回归.md)。

四样本训练 1000 步后，得到约 `w = [2, -1]、b = 1`，损失约 `1.46 × 10⁻¹⁷`。

### 换样本数复用

文末源码还用五条两特征样本复用相同训练设置，得到约 `w = [-2, 3]、b = 2`，新输入 `[2, -1]` 的预测约为 `-5`。这项对照用于检查函数是否按新样本数 `5` 求平均，而非沿用四样本实验的全局 `m`。

这些构造数据用于核对公式与实现；一次新输入预测不能代替独立数据集评价。

## 单特征是多特征公式的特例

只有一个特征时，仍保留 `X` 的二维形状 `(m, 1)`，权重形状为 `(1,)`。这样可以用同一公式与原单变量实现对照。

对照使用前篇的 `x = [0,1,2,3]`、`y = [1,3,5,7]`，将输入变为二维单列、标量权重变为单元素数组即可。使用相同初始参数时，损失、梯度和一步更新均与[单变量数组实现](./03_NumPy数组与批量计算.md#与循环版对照)一致；不能把另一组数据删掉一列后当作原实验的等价版本。

## 删去特征后为何无法零误差

**原来的标签对应的是包含两个特征的样本。删除一个特征后，模型可利用的信息减少了，可能无法再区分原本不同的样本，因此可能无法达到原来的预测精度。**

例如，开头四条样本使用 `X[:, 0:1]` 保留二维单列输入后，训练得到约 `w = [2]、b = 0.5`，预测为 `[0.5, 2.5, 0.5, 2.5]`，损失为 `0.125`。此时两条不同样本可能具有相同输入却对应不同标签，确定性模型无法同时匹配，继续增加训练步数也不能补回已删除的信息。

## 特征缩放与标准化

不同特征的量级相差较大时，各个权重梯度受对应特征值的影响也可能相差较大。同一个学习率下，某些方向的更新可能过大，影响训练的稳定性和收敛速度。

标准化按列减去训练均值、除以训练标准差：`x_scaled_j = (x_j - mu_j) / sigma_j`。`axis=0` 表示沿样本方向计算，为每列特征得到一个统计量。

以下按缩放实验整理，沿用前文的 `train_multi`；各列标准差均非零：

```python
X_train = np.array([[-100, 0],
                    [100, 0],
                    [0, -1],
                    [0, 1],
                    [100, 1]], dtype=float)
y_train = np.array([4, 0, -1, 5, 3], dtype=float)

mu = np.mean(X_train, axis=0)
sigma = np.std(X_train, axis=0)
X_scaled = (X_train - mu) / sigma
w_scaled, b_scaled = train_multi(X_scaled, y_train, np.zeros(2), 0.0, 0.1, 40)

X_new = np.array([[200, -1]], dtype=float)
X_new_scaled = (X_new - mu) / sigma
prediction = X_new_scaled @ w_scaled + b_scaled
```

**新样本沿用训练集的统计量，并使用标准化输入上训练得到的参数。** 不能重新用新样本计算均值和标准差，也不能把标准化模型的参数直接用于原始输入。训练统计量的来源见[预处理与数据泄漏](./01_训练、评估与数据泄漏.md)。

本例 `mu = [20, 0.2]`，`sigma` 约为 `[74.833148, 0.748331]`；新输入标准化后约为 `[2.405351, -1.603567]`，第 40 步模型的预测约为 `-4.646771`。

标准化不保证数值落在 `[-1, 1]`，也不会把任意数据分布变成正态分布。若某列标准差为零，不能直接套用除法；本例没有这种情况。

### 用控制变量限定结论

两组使用相同样本与标签、零权重和零偏置、学习率 `0.1`、更新 `40` 步，只改变输入是否标准化。零参数使两组初始预测相同；各记录含第 0 步在内的 41 个损失。

| 观察量 | 原始输入 | 标准化输入 |
| --- | ---: | ---: |
| 初始损失 | `5.1` | `5.1` |
| 第 40 步损失 | 约 `5.214 × 10²²⁰` | 约 `0.00718695` |
| 首次达到 `J < 0.01` | 40 步内未达到 | 第 38 步 |

在这些条件下，原始组发散，标准化组损失稳定下降并达到阈值。这不能推出原始输入在更小的学习率下也无法训练，更不能推出标准化后泛化能力更强；实验没有独立测试集上的预测评价。

观察训练时可记录每步损失、检查突增或震荡，并比较达到同一损失阈值所需的步数。**达到阈值不等于完全收敛**，相邻损失变化小也不足以证明已经到达最优点。
