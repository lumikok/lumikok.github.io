# 神经网络前向与反向传播

## 网络层与特征学习

神经网络由输入层、隐藏层和输出层组成。输入层接收原始特征；隐藏层把上一层输出重新加权、加偏置，再经过激活函数，形成新的特征表示；输出层根据这些表示给出预测。隐藏层可以有多层，每层的神经元数称为该层宽度。

可以把这里的二分类网络理解为：先学习特征表示，再用类似逻辑回归的输出层分类。训练时给出输入和正确标签，通过损失调整隐藏层与输出层参数，无需逐个指定隐藏神经元应提取什么特征；但这不保证每个神经元都有直观含义，也不保证训练后一定学到有效表示。

本例使用梯度下降训练：**前向传播计算预测和损失，反向传播计算各参数的梯度，梯度下降利用梯度更新参数。** 反向传播本身不执行参数更新。

## 前向传播与数组形状

以下沿用实验的“样本按行、每列权重对应一个神经元”约定。输入层记为第 0 层，隐藏层为第 1 层，输出层为第 2 层：

```text
z1 = x @ W1 + b1
a1 = sigmoid(z1)
z2 = a1 @ W2 + b2
a2 = sigmoid(z2)
```

`z` 是激活前得分，`a` 是激活值；本例最终概率 `p = a2[0]`。sigmoid 与交叉熵的定义见[逻辑回归](../machine-learning/05_逻辑回归.md)。

设输入特征数为 `d`，隐藏层宽度为 `h`，输出层只有一个神经元，批量样本数为 `m`：

| 量 | 单样本形状 | 批量形状 |
| --- | --- | --- |
| 输入 `x / X` | `(d,)` | `(m,d)` |
| 隐藏层 `z1、a1 / Z1、A1` | `(h,)` | `(m,h)` |
| 输出层 `z2、a2 / Z2、A2` | `(1,)` | `(m,1)` |

参数形状分别为 `W1: (d,h)`、`b1: (h,)`、`W2: (h,1)`、`b2: (1,)`。偏置在批量运算中广播到每条样本；改变隐藏层宽度会改变 `W1、b1、W2`，不会改变最终输出的维数。

**层号与神经元索引不同。** `a1[1]` 是第 1 层第 2 个神经元的激活值，数学上可记为 $a^{[1]}_2$；`a2` 则是第 2 层的激活数组。代码索引从 0 开始。

实验使用以下参数：

```python
W1 = np.array([[0.5, -1.0], [-0.25, 0.0]])
b1 = np.array([0.2, 0.0])
W2 = np.array([[1.0], [-2.0]])
b2 = np.array([0.0])
```

输入 `x=[1,2]` 时，`z1=[0.2,-1]`，`a1≈[0.549834,0.268941]`，最终 `z2≈0.01195115`、`p≈0.50298775`。三条输入 `[[1,2],[0,0],[2,-1]]` 的隐藏层、输出层形状分别为 `(3,2)`、`(3,1)`，第一条结果与单样本计算一致。

得分与概率不能混用：`sigmoid(0.2)≈0.5498`，所以得分大于 0 对应激活值大于 0.5。判断最终类别时，应使用输出层概率与相应阈值比较。

## 隐藏层为什么需要非线性

去掉隐藏层激活，保留输出层 sigmoid，则输出得分为：

```text
Z2 = (X @ W1 + b1) @ W2 + b2
   = X @ (W1 @ W2) + (b1 @ W2 + b2)
```

令 `W_merged=W1@W2`、`b_merged=b1@W2+b2`，便可合并成一次仿射变换，再接 sigmoid，即逻辑回归。本例合并权重为 `[2.5,-0.25]`、偏置为 `0.2`，三条输入的两种计算结果 `np.allclose` 为 True。

因此，单纯堆叠线性隐藏层不会增加这种模型的表达能力。若连输出层也没有非线性，整体仍只是仿射模型；加入隐藏层非线性后，通常不能再这样合并。

## 反向传播与负系数路径

反向传播从损失出发，沿前向计算的依赖关系反向应用链式法则，得到损失对权重、偏置的梯度。它计算梯度的方向与前向计算相反，但不是把输出反解成输入。

对本例 sigmoid 输出与二分类交叉熵，有 `dL/dz2 = p-y`，推导见[链式法则与分类梯度](../machine-learning/05_逻辑回归.md#链式法则与分类梯度)。

选隐藏层权重 `q=W1[1,1]`，影响路径为：

```text
q → z1[1] → a1[1] → z2[0] → L

dL/dq = (p-y) × W2[1,0] × a1[1](1-a1[1]) × x[1]
```

取 `x=[1,2]、y=1` 和上述初始参数：`p-y<0`，但路径上的输出权重 `W2[1,0]=-2` 也为负，另外两个因子为正，因此 `grad_q≈+0.39087415`。增大 `q` 会让隐藏激活增大，经负输出权重后压低最终概率，使标签为 1 的损失增大。

**梯度与参数新值不同。** 学习率为 `0.1` 时：

```text
q_new = q_old - learning_rate × grad_q
      = 0 - 0.1 × 0.39087415
      ≈ -0.03908742
```

不能只根据 `p-y` 判断隐藏层权重的更新方向，也不能漏掉学习率。

### 单样本的四组梯度

以下为 `network_core.py` 中的核心计算片段，沿用前向得到的 `a1、a2`；适用于本例单个 sigmoid 输出和交叉熵损失：

```python
dz2 = a2 - y
dW2 = dz2[:, np.newaxis] * a1[:, np.newaxis]
db2 = dz2

dz1 = (W2.flatten() * dz2) * a1 * (1 - a1)
dW1 = x[:, np.newaxis] * dz1[np.newaxis, :]
db1 = dz1
```

`dz2、dz1` 分别表示损失对两层得分的梯度。隐藏层先接收输出层传回的变化率，再乘 sigmoid 的局部导数；权重梯度还要乘对应输入。四组参数梯度的形状必须与各自参数一致。

这里 `dz2` 的形状为 `(1,)`，所以 `dW2` 得到 `(h,1)`；`dW1` 将 `(d,1)` 与 `(1,h)` 相乘，得到 `(d,h)`。这些写法限定于当前单输出网络，扩展多输出时不能直接照搬。

## 用中心差分检查梯度

解析梯度来自链式法则；数值差分通过轻微扰动参数，估计损失随参数变化的快慢。中心差分为：

$$
\frac{\partial L}{\partial q}\approx\frac{L(q+\varepsilon)-L(q-\varepsilon)}{2\varepsilon}
$$

检查时固定输入、标签和其他参数，只改变一个参数元素，并从原参数副本分别计算正、负扰动。差分结果应与同一原始位置的解析梯度比较。

本例 `epsilon=1e-5`，`q` 的解析梯度约 `0.390874154845394`，数值梯度约 `0.390874154843068`，绝对差约 `2.33e-12`。另检查 `W1[0,0]、b1[1]、W2[0,0]、b2[0]`，绝对差均小于 `1e-6`。

这是对所检查点的数值核对，不是所有参数和输入都正确的证明，也不是训练集/验证集划分意义上的“交叉验证”。

## 平均梯度与训练结果检查

多样本训练优化平均损失，其梯度也是各样本梯度的平均值：

$$
J(\theta)=\frac{1}{m}\sum_{i=1}^{m}L_i(\theta),\qquad
\nabla J(\theta)=\frac{1}{m}\sum_{i=1}^{m}\nabla L_i(\theta)
$$

一次全批量更新的顺序是：

1. 所有样本用同一组旧参数计算梯度，分别累加四组梯度。
2. 各除以样本数 `m`，得到四组平均梯度。
3. 全部梯度计算完毕，再按 `参数 -= 学习率 × 平均梯度` 更新四组参数。
4. 用新参数重新计算并记录平均损失和预测概率。

逐样本循环求梯度、最后平均并更新一次，仍是全批量梯度下降；在循环中每算一条就更新参数，便改变了算法。同样，计算隐藏层梯度时必须使用旧 `W2`，不能先更新输出层再计算隐藏层梯度。

实验三条样本为 `X=[[1,2],[0,0],[2,-1]]、y=[1,0,1]`，使用上述初始参数和学习率 `0.1`：一步平均损失从 `0.54267342` 降至 `0.53540200`，100 步降至 `0.32424605`。这是训练数据上的结果，不能据此判断新样本上的效果。

记录与模型还应相互对应：

- 保留初始状态时，100 步训练应有 101 条损失记录，并检查是否出现 `nan/inf`。
- 更新的是参数副本时，返回值必须是实际训练后的副本。副本叫 `W1` 还是 `W1_train` 都可以，关键是更新与返回指向同一组参数。
- 用返回参数重新计算损失、概率，应与最后一条记录一致；本例两项检查均为 True。日志下降本身不能证明调用方拿到了训练后的模型。
- `loss_batch` 逐样本计算后返回的概率为 `(m,)`；批量前向输出为 `(m,1)`，与 `(m,)` 标签相减前需统一形状，避免广播成 `(m,m)`，见[NumPy 数组与批量计算](../machine-learning/03_NumPy数组与批量计算.md)。
