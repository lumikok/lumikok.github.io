# SQLAlchemy 聚合查询与结果

SQL 的聚合、分组与查询顺序已有[MySQL 基础](../mysql/基础.md)，此处补充 SQLModel/SQLAlchemy 构造和读取结果的写法。

## 构造分组查询

```python
from sqlalchemy import func
from sqlmodel import select

statement = (
    select(
        Expense.category,
        func.sum(Expense.amount).label("amount"),
        func.count(Expense.id).label("count"),
    )
    .where(Expense.date >= start_date, Expense.date <= end_date)
    .group_by(Expense.category)
    .order_by(Expense.category)
)
rows = (await session.exec(statement)).all()
```

示例中的 `Expense` 是表模型，`session` 是异步 SQLModel 会话。

- `func.sum()`、`func.count()` 构造 SQL 函数，不是对 Python 列表计算；
- `where()` 在聚合前筛选记录，`having()` 筛选聚合后的分组；
- `group_by()` 指定分组键；`label()` 命名结果列；
- 选出的非聚合列通常应出现在分组键中；`COUNT(column)` 只统计非空值。

## 结果形态

| SQLModel `session.exec(select(...))` 的内容 | 常见结果 |
| --- | --- |
| 一个模型 `select(Expense)` | 模型对象 |
| 单个聚合表达式 `select(func.sum(...))` | 标量，如金额或 `None` |
| 多个列/表达式 | 行对象，可按位置解包 |

```python
summary = [
    {"category": category, "amount": amount, "count": count}
    for category, amount, count in rows
]

total = (await session.exec(select(func.sum(Expense.amount)))).one()
total = 0 if total is None else total
```

没有 `GROUP BY` 的 `SUM` 在无匹配行时通常得到一个 `NULL` 结果；带分组的无匹配查询通常得到空结果列表。是否将 `NULL` 转成 0，应由返回契约决定。

SQLAlchemy 原生 `session.execute()` 的结果 API 与 SQLModel `exec()` 不同，不能机械混用；原生查询可按需求使用 `scalar_one()`、`scalars()` 或 `mappings()`。

易错点：已聚合的总额不能再乘记录数；总额和记录数是两个不同统计量。

参考：[SQLAlchemy SELECT 与聚合](https://docs.sqlalchemy.org/en/20/tutorial/data_select.html)。
