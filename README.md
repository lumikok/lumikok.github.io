# lumikok 的个人网站

用于构建和维护 [lumikok.github.io](https://lumikok.github.io/) 的网站源码仓库，基于 VitePress 与 `@sugarat/theme`。

网站收录个人学习笔记、技术与生活文章、项目实践、竞赛经历和成长足迹。内容主要使用 Markdown 编写，侧边栏与文章、项目索引由脚本自动生成。

## 仓库结构

- `docs/`：网站页面、Markdown 内容与静态资源。
- `docs/.vitepress/`：站点配置、主题与样式。
- `scripts/`：内容索引、侧边栏生成及链接检查脚本。

网站通过 GitHub Pages 发布。
